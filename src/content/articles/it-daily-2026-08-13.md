## 一、认证动态

### 1. AWS Advanced Networking Specialty（ANS-C01）八月二十五日最后一天可考

**一句话**：ANS-C01 在十二天后永久停考，AWS 尚未公布任何直接替代考试。

AWS Advanced Networking Specialty 是 AWS 认证体系里含金量最高的专项考试之一，考察混合网络设计、VPC 高级配置、Transit Gateway、Direct Connect 与 VPN 架构等内容。这张证经常出现在大型企业的 Cloud Architect 职位要求里，也是国内不少拿 SAA 之后想进一步冲 AWS 专业认证的首选路径。

关键时间：**2026 年 8 月 25 日（星期二）是最后一天可以预约并完成考试。** 已经预约但在这天之前没考的人，预约依然有效；25 日之后，无论线上还是考场，ANS-C01 全部停开。

已拿到这张证的人无需担心——在有效期内（通常三年）正常续签，退场对现有证书没有影响。还没考但正在备考的人：AWS 没有宣布直接替代，意味着这个知识点体系短期内不会有新的单独认证覆盖。如果学员已备考 70% 以上，这十二天内找一个 Pearson VUE 或 PSI 考位冲一次是合理选择；如果才刚起步，建议等待 AWS 官方后续公告再决定方向。

> 来源：[CertCrush – AWS Advanced Networking Specialty Retiring 25 August 2026](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026)

### 2. Azure AZ-500 八月三十一日退场，SC-500「云与 AI 安全工程师」已开放报名

**一句话**：AZ-500 月底停考，替代考试 SC-500 已于七月二十一日上线，两者都能拿到安全类 Associate 认证，但考纲侧重已经从纯 Azure 扩展到 AI 安全威胁。

这是本月 Azure 认证里影响面最广的一次退场。**AZ-500: Microsoft Azure Security Technologies** 运行了多年，是 Azure 安全方向的核心入门证，国内外考 Azure 安全工程师的人几乎都走这条路。

从八月三十一日起，AZ-500 正式停考。接班的是 **SC-500: Microsoft Cloud and AI Security Engineer Associate**，七月二十一日已正式上线，对应认证名称更新为 **Microsoft Certified: Cloud and AI Security Engineer Associate**。

SC-500 与 AZ-500 的主要差异：
- 考纲新增 AI 应用安全威胁（prompt injection、模型篡改、AI 服务访问控制）
- 扩展了 Microsoft Defender for Cloud Apps 与 Microsoft Sentinel 的覆盖深度
- 减少了传统网络安全配置细节，更偏向安全架构决策

**现在该怎么做**：已经在备考 AZ-500 且快考完的人，尽快在 8 月 31 日前约好考位。刚开始备考或还在看教材的人，直接切到 SC-500 更划算——新考纲会是今后几年 Azure 安全岗位 JD 里出现的认证。

> 来源：[Pearson VUE – Microsoft Exam Updates & Certification Changes](https://www.pearsonvue.com/us/en/microsoft/updates.html)

### 3. Azure PL-200 八月三十一日退场，AB-410「智能应用构建师」七月底已上线

**一句话**：Power Platform 方向的 Functional Consultant 考试（PL-200）被 AI 应用构建师考试（AB-410）取代，月底截止，两张证的就业方向差异值得看一眼再决定。

**PL-200: Microsoft Power Platform Functional Consultant Associate** 同样在 8 月 31 日停考。这张证原本考的是 Power Apps 建模驱动型应用、Power Automate 流程、Dataverse 数据配置，是做低代码解决方案的 BA/Consultant 常备认证之一。

取代 PL-200 的是 **AB-410: Microsoft Intelligent Applications Builder Associate**，对应认证更新为 **Microsoft Certified: Intelligent Applications Builder Associate**，于 2026 年 7 月 30 日正式上线。AB-410 的重心从传统 Power Platform 配置转向 AI Builder、Copilot Studio、以及在 Power Platform 生态里接入和调用 Azure OpenAI 服务的能力。

对在职的 Functional Consultant 或做 Power Platform 集成工作的学员而言，AB-410 的内容方向更符合甲方当前的实际采购方向——越来越多企业在 RFP 里开始要求 Copilot Studio 集成经验。PL-200 原备考材料可以约 60% 复用，新增的 AI Builder 和 Copilot Studio 部分需要额外补充。

> 来源：[Pearson VUE – Microsoft Exam Updates & Certification Changes](https://www.pearsonvue.com/us/en/microsoft/updates.html)

### 4. Google Cloud 专业认证一次性续签延期：九月一日关窗

**一句话**：GCP 把认证考试迁到 Pearson VUE 时顺带给了一次续签宽限期，但这个宽限在九月一日截止——持有 PCA、PDE、ACE 或 CDL 且认证今年失效的人本周就要行动。

背景：Google Cloud 在 2026 年 2 月 26 日完成了从 Kryterion/Webassessor 到 Pearson VUE 的考试平台迁移，同步推出了新的 **Google Skills 续签路径**——不需要重考整套题，通过在线评估即可续签。

为了让持证人适应新系统，Google 提供了一次一次性延期政策：**如果你的 PCA（Professional Cloud Architect）、PDE（Professional Data Engineer）、ACE（Associate Cloud Engineer）或 CDL（Cloud Digital Leader）认证在 2026 年 1 月 1 日或之后到期，或将在 2026 年 8 月 31 日之前到期，那么你有一次机会通过 Google Skills 续签路径把认证续到下一个周期**——但这个窗口在 **2026 年 9 月 1 日** 关闭。

操作路径：登录 [Google Skills](https://www.skills.google/)，进入你的认证续签界面，按照 Google Skills 续签评估流程操作。不同于重考，这个评估专门针对续签设计，题量和难度均低于新考。

**明确适用人群**：近两年通过 PCA/PDE/ACE/CDL 并已到期或即将到期的学员，这是今年内唯一的免重考续签机会，错过只能重考全套。

> 来源：[DailyDebian – Google Cloud Changed Exam Delivery and Renewal Rules in 2026](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)

**链接**：[https://aws.amazon.com/training/digital/](https://aws.amazon.com/training/digital/)

AWS 官方 Skill Builder 平台的免费层课程里，Cloud Practitioner Essentials 是入门层里内容最完整的一门：6 小时自学内容，覆盖云计算概念、AWS 核心服务（EC2、S3、RDS、Lambda）、安全基础、定价与计费模型，全程英文但配有字幕选项。

这门课不需要任何前置知识，适合做技术支持、PM、BA 或正在转行到云领域的学员。考 CLF-C02 的人把这门课配合 AWS 官方 Sample Questions 一起刷，已经覆盖了大约 70% 的考试知识点。

Skill Builder 还有一个免费的 **AWS Cloud Quest（Cloud Practitioner 版本）**，以 RPG 游戏形式完成 AWS 实操任务，比纯看视频记忆效果更好，特别推荐动手能力强但不爱看教材的学员。

**适合**：编程零基础或想系统补计算机科学基础的学员，不分年龄和背景
**链接**：[https://cs50.harvard.edu/x/](https://cs50.harvard.edu/x/)

CS50x 是 edX 上极少数真正"免费且含证书"的课程之一，由哈佛大学出品，常年是 Class Central 全球 MOOC 评分排名前三的课程。课程覆盖 C、Python、SQL、HTML/CSS/JavaScript，以及数据结构和算法基础，总时长约 100–150 小时。

对找第一份 IT 工作、需要在简历上展示编程基础的求职学员而言，CS50x 证书在海外招聘市场的认可度相当高，不少 JR Academy 学员把它配合 Java/Python bootcamp 简历一起展示。

## 三、JR Academy 学员行动建议

1. **已持有 AWS ANS-C01 的学员**：证书不受影响，到期续签路径不变，放心。还没考但备考超过 60% 的人：登录 [Pearson VUE AWS 预约页](https://home.pearsonvue.com/aws) 在 8 月 25 日前找一个考位，这是最后机会。

2. **Azure 安全方向学员**：AZ-500 还没过的人现在改报 **SC-500**，旧教材可以用，新增 AI 安全部分在 Microsoft Learn 的 SC-500 学习路径里有免费模块，补一周左右。月底前还想拼 AZ-500 的人：确认你的考位日期在 8 月 31 日当天 23:59 前。

3. **Power Platform/低代码方向学员**：直接学 **AB-410**，不要再投入时间在 PL-200 备考资料上。Copilot Studio 和 AI Builder 在当前市场的需求比传统 Dataverse 配置岗位增长更快。

4. **持有到期 GCP 证书的学员**：在 9 月 1 日前登录 [Google Skills](https://www.skills.google/)，找到你的证书续签入口，完成 Google Skills 续签评估——这是比重考便宜且简单的唯一路径，窗口关了就只能全套重考。

5. **备考 AWS 入门或想夯实云基础的学员**：今天就去 AWS Skill Builder 开始 Cloud Practitioner Essentials（免费，6 小时），同时打开 Cloud Quest（免费，游戏形式），两条线并行两周内就能把 CLF-C02 的核心考点跑完一遍。
