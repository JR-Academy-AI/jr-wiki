## 一、认证动态

### 1. AWS Maintain Open Beta：攒积分延期一年，AWS 认证首次不用重考

**一句话**：2026年6月23日，AWS 悄悄上线了一个改变认证规则的程序——只要在 Skill Builder 完成指定学习任务，已有认证可以直接延期 12 个月，不用再刷题、不用再考场签到。

**AWS Maintain**（官方名：AWS Maintain Open Beta）于 2026年6月23日正式开放测试，是 AWS 认证体系首个"免试续期"路径。具体规则：

- **Associate 级别**：在 AWS Skill Builder 完成指定数字课程 + 动手实验，达到 **500 积分**即可申请延期
- **Professional 级别**：需达到 **700 积分**，且有最低动手实验比例要求（实验必须在真实 AWS 环境中操作，非视频浏览）
- **级联延期**：维持高级别认证时，关联的低级别认证自动顺延，一次操作多证延期

**当前可用认证（Beta 阶段）**：
- AWS Certified Solutions Architect – Professional / Associate
- AWS Certified DevOps Engineer – Professional
- AWS Certified Developer – Associate
- AWS Certified CloudOps Engineer – Associate

**2026年晚些时候加入**：Data Engineer – Associate、Security – Specialty、Machine Learning Engineer – Associate

**使用前提**：需要有效的 AWS Skill Builder 订阅，且认证必须在 **到期前 90 天内** 才能启动 Maintain 流程——提前太早不行，得卡好窗口。

**JR 学员怎么判断值不值**：如果你已经有 SAA-C03 或者 DVA-C02，且距到期不到 3 个月，先算一算 Skill Builder 年订阅 vs 重考费（Associate 约 $150 USD）的差价，Maintain 适合已经有 Skill Builder 订阅的人吃到额外价值。

> 来源：[A new way to keep your AWS Certification current — AWS Training and Certification Blog](https://aws.amazon.com/blogs/training-and-certification/a-new-way-to-keep-your-aws-certification-current/)

### 2. Databricks Certified Context Engineer Associate：全球首张 AI Agent 上下文工程认证，7月29日首考

**一句话**：AI agent 时代到来，真正的技术难点不是"写 agent 代码"，而是"给 agent 喂什么信息、喂多少、怎么管理"——Databricks 认为这一技能缺口够大，专门造了一张认证。

2026年5月19日，Databricks 宣布推出 **Databricks Certified Context Engineer Associate**，自称是"全球首张专门针对 AI Agent 系统可靠性的认证"（the industry's first certification for reliable AI agent systems）。**首次考试于 2026年7月29日（昨天）开放**。

**考试基本信息**：
- **费用**：$200 USD
- **时长**：120 分钟
- **形式**：在线监考（Live Proctored），多选题
- **推荐经验**：6个月以上 AI Agent context engineering 实际操作经验

**考什么**：这张证不考"怎么写 agent"，考的是信息管理层面：

1. **系统提示词与指令结构化**（Structuring system prompts and instructions）
2. **检索系统配置**（AI Search 等 RAG 检索组件的配置与优化）
3. **Memory 架构设计**：用 Lakebase 和 MLflow 实现跨 session 状态持久化
4. **Context Window 管理**：通过 compaction（压缩）和 trimming（裁剪）控制上下文长度
5. **Unity Catalog 治理**：metadata 管理、PII 处理、policy enforcement
6. **多 Agent / 长任务流**（Long-horizon workflow）的上下文策略
7. **上下文决策的实验评估**（Empirical evaluation of context engineering decisions）

**为什么值得关注**：在 job listing 上，"context engineering"这个词的出现频率从 Q1 2026 开始显著上升，但市面上没有任何一张证书能在简历上标注这一技能。先考先占坑。

> 来源：[Databricks context engineer associate: the industry's first certification for reliable AI agent systems — Databricks Blog](https://www.databricks.com/blog/databricks-context-engineer-associate-industrys-first-certification-reliable-ai-agent-systems) · [Exam info from Databricks Community](https://community.databricks.com/t5/community-articles/i-took-the-databricks-context-engineer-associate-beta-exam-here/td-p/159924)

### 3. AZ-500 下月31日退役，SC-500 接班上阵

**一句话**：AZ-500 给了你整个 8 月，但 9 月1日起这张证将永久无法再考，替代者 SC-500 专门加了一整块 AI 安全考域。

微软已确认：**AZ-500（Microsoft Certified: Azure Security Technologies）将于 2026年8月31日正式退役**，考试、认证、续期评估同步下线，不设宽限期。

接班者是 **SC-500（Exam SC-500: Implementing End-to-End Security Controls for Cloud and AI Workloads）**，对应认证头衔 **Microsoft Certified: Cloud and AI Security Engineer Associate**。

**SC-500 vs AZ-500 的核心差异**：

| 维度 | AZ-500 | SC-500 |
|---|---|---|
| 定位 | Azure 云安全专项 | Azure + 混合云 + AI 全栈安全 |
| 考域 | 身份/网络/存储/计算安全 | 以上全部 + **AI 管道安全 / GenAI 威胁防御 / Agentic AI 系统治理** |
| AI 安全 | 不涉及 | 专门考域，包括 AI 模型安全、AI 工作流漏洞、RAG 架构攻击面 |

**Beta 阶段**（5月15日起）前 300 名有 80% 折扣优惠（已截止）；GA 阶段正常考试费用请到 [learn.microsoft.com/credentials/certifications/cloud-ai-security-engineer](https://learn.microsoft.com/credentials/certifications/cloud-ai-security-engineer/) 核实。通过分数为 700/1000，考试时长 120 分钟。

**还在备考 AZ-500 的同学怎么选**：
- 已经备考 70% 以上、8月内有档期 → 去考 AZ-500，证书有效期正常 3 年
- 刚开始备考或时间不确定 → 直接转 SC-500，AI 安全是增量，AZ-500 的材料有约 60% 可以复用

> 来源：[Question Regarding the Future of the AZ-500 Certification — Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/5953548/question-regarding-the-future-of-the-az-500-certif) · [New Microsoft Certified: Cloud and AI Security Engineer Associate — Microsoft Tech Community](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-cloud-and-ai-security-engineer-associate-certification/4494117)

### 4. Google Cloud 认证三项更新：Skills Badge 可以当续期方式用了

**一句话**：从 2026年7月起，GCP 用户可以不重考，靠完成 Google Skills 课程 / Badge 来续期 PCA、PDE、ACE、CDL 四张证书。

谷歌在 2026年7月对认证续期规则做了调整，**新增第三条续期路径**（在重考正版和重考短版之外）：

- 覆盖认证：**Professional Cloud Architect（PCA）/ Professional Data Engineer（PDE）/ Associate Cloud Engineer（ACE）/ Cloud Digital Leader（CDL）**
- 方式：在认证有效期的最后一年内，完成 Google Skills 平台上指定的课程或 Skill Badge
- 注意：只有在"有效期最后一年"内完成的课程才计数，提前完成不算

**宽限期政策**：如果你的 PCA/PDE/ACE/CDL 在 2026年1月1日至8月31日之间到期，将获得一次性延期至 **2026年9月1日**，专门让你有时间试用新的 Skills Badge 续期路径。

**ACE 考题更新**：2026年6月30日起，参加 Associate Cloud Engineer 考试的考生将面对更新后的英文题库，覆盖范围对齐 2026 版 GCP 服务能力。旧版题库的准备材料需要对照更新。

> 来源：[Certification Renewal — Google Cloud Certification Help](https://support.google.com/cloud-certification/answer/9907853?hl=en) · [Google Cloud Certification Changes 2026 — DailyDebian](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)

## 三、JR Academy 学员行动建议

1. **持有 AWS Associate / Professional 且 3 个月内到期**：立即进 [skillbuilder.aws](https://skillbuilder.aws) 查看 Maintain 计划是否对你的认证开放，500 积分的工作量折算下来大约 20–30 小时，明显比重考划算。AWS Skill Builder 年订阅价格请以官网为准。

2. **正在学 Azure 安全方向**：AZ-500 最后考试窗口到 **8月31日**。如果你已经备考超过一半，这个月拿掉；如果刚开始，直接对准 SC-500，新材料更贴近 2026 年 AI 安全职位需求，求职竞争力更强。

3. **数据工程师 / AI 工程师在找职位**：Databricks Context Engineer Associate 是目前市场上唯一一张专门考察 AI Agent 上下文管理能力的证书，考费 $200 USD，考纲在 [databricks.com/learn/certification](https://www.databricks.com/learn/certification) 可下载。有 Databricks 实操经验的同学趁早卡位，同类认证扩散后难度会越来越高。

4. **持有 GCP PCA / PDE / ACE / CDL 且近期到期**：如果你的证书在今年 1月–8月之间到期，你有宽限期到9月1日，可以用新的 Skills Badge 路径续期，比重考节省时间和费用。进 Google Cloud Skills Boost 找对应徽章，完成即可。

5. **想用最低成本拿可验证 AI 技能证明的**：AWS Agentic AI Demonstrated 完全免费 + Google Cloud Agentic AI Badge 免费，两个都做完大约 3–5 天，LinkedIn 上可以展示两个厂商的 AI 实操验证——这比单纯的"会用 ChatGPT"可信度高多了。
