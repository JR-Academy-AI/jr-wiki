接班者是 **AI-200（Developing AI Cloud Solutions on Azure）**，考取后授予 **Azure AI Cloud Developer Associate** 认证，正式于 2026年7月 GA（Beta 于 4月2日开放，前300名可用优惠码 **AI200Piedmont** 享 8折优惠）。

### 2. Databricks Context Engineer Associate 首考今日开幕（7月29日）

**一句话**：全球第一批 Context Engineer 认证持有人今天产生——Databricks 的 AI Agent 上下文工程认证 7月29日首次开放考试，$200、120分钟、专考 MCP 集成 + 记忆架构 + 上下文窗口管理。

Databricks 的 **Certified Context Engineer Associate** 认证于**2026年7月29日**（今天）正式首考，这也是全球 IT 认证体系里首个专门针对 AI Agent 上下文工程能力的认证。

**考试规格：**

- **费用**：$200 USD
- **时长**：120 分钟
- **题型**：在线监考 + 多选题
- **有效期**：2 年
- **推荐经验**：6 个月以上 AI Agent 上下文工程实操

**考试涵盖核心技能（三大模块）：**

1. **记忆架构设计**：使用 Lakebase + MLflow 实现跨 Session 的状态持久化
2. **MCP 工具集成**：将 Agent 与外部工具 / 数据源通过 Model Context Protocol 打通
3. **上下文窗口管理**：通过 compaction（压缩）和 trimming（裁剪）策略控制输入 token 用量

在 Databricks Data + AI Summit 2026（DAIS 2026）上，Beta 考试已经开放给提前注册的参与者，首批约 90 题、120 分钟。今日的正式首考是 Beta 之后的第一次对外开放。

**为什么现在值得考：**

Context Engineering 是 2026 年 AI 岗位需求最快增长的方向之一。拿到这张认证，相当于在 AI Agent 工程这个细分领域有了第一个可信的能力证明。从已有的 Databricks 认证体系（Data Engineer Associate / Machine Learning Associate）来看，$200 的定价比 AWS Professional 和 Azure Expert 都低，性价比高。

> 来源：[Databricks — Certified Context Engineer Associate](https://www.databricks.com/learn/certification/context-engineer-associate) / [Databricks Blog — Industry's First Certification for Reliable AI Agent Systems](https://www.databricks.com/blog/databricks-context-engineer-associate-industrys-first-certification-reliable-ai-agent-systems)

### 3. Google Cloud ACE 2026 新增免费续期路径：刷课程/徽章替代 $75 考试

**一句话**：Google Cloud 从 2026年7月起，持有 Associate Cloud Engineer 认证的用户可以通过在 Google Skills 完成指定课程或徽章来续期——免费、无需再考 $75 的续期考试，但续期后仅延长 1 年。

Google Cloud 现在为 **Associate Cloud Engineer（ACE）** 认证提供三条续期路径：

| 续期方式 | 费用 | 有效延长时间 |
|------|------|------|
| 重考标准考试（125题，2小时） | $125（含税） | 3 年 |
| 续期考试（20题，1小时） | $75（含税） | 3 年 |
| **🆕 完成 Google Skills 课程/徽章** | **免费** | **1 年** |

**新路径关键限制（官方原文）**：

> "Only course/badge completions in the **final year of your certification's active period** count toward renewal — finishing relevant Google Skills content two years before expiration doesn't bank credit early."

也就是说：如果你的 ACE 还有 2 年才到期，现在刷课程不算数，必须等进入最后一年才开始刷。适合刷课的时机窗口：认证到期前 12 个月以内。

**此外，ACE 2026 Grace Period（截止 2026年9月1日）**：

2026年1月1日至8月31日之间过期的 ACE 认证，可以在 **2026年9月1日之前**通过完成 Google Skills 活动恢复有效状态，无需重考。

**新版 ACE 考题（2026年6月30日起生效）**：标准考试和续期考试均已更新，精简冗余内容、优化题目覆盖面，减少重复考核。

> 来源：[Google Cloud — Associate Cloud Engineer Certification](https://cloud.google.com/learn/certification/cloud-engineer)（官方页面，2026-07-29 验证）

### 4. AWS AIP-C01 Generative AI Developer Professional：$300 正式上线

**一句话**：AWS 最新的 AI 认证 AIP-C01（Generative AI Developer – Professional）Beta 已于 3月31日结束，现已正式上线，标准价 $300，65 道题、204 分钟、750 分通过，3 年有效期。

**AWS Certified Generative AI Developer – Professional（AIP-C01）** 是 AWS 在 2026 年扩展 AI 认证体系后推出的 Professional 级别 AI 工程认证。Beta 测试阶段（到 2026年3月31日）价格为 $150，Beta 结束后正式定价：

- **考试费用**：$300 USD
- **题量**：65 道计分题 + 10 道非计分题（共 75 题）
- **考试时长**：204 分钟（约 3.4 小时）
- **及格分数**：750 / 1000
- **有效期**：3 年

**核心考域**：生成式 AI 基础（Amazon Bedrock、SageMaker JumpStart）、Prompt Engineering、RAG 管道构建、AI Agent 开发（Amazon Q / Agents for Bedrock）、AI 安全与 Responsible AI。

与 AWS AI Practitioner（AIF-C01，$150）的区别：AIP-C01 面向**实际动手开发** AI 解决方案的工程师，需要写代码、配置 RAG pipeline、理解 fine-tuning 工作流；AIF-C01 更偏基础概念，不需要写代码。

AWS 方向的学员如果已经有 SAA-C03 或 DVA-C02，AIP-C01 是目前含金量最高的垂直方向扩展。

> 来源：[Pluralsight — New AWS AIP-C01 Exam](https://www.pluralsight.com/resources/blog/cloud/new-aws-aip-c02-exam) / [FlashGenius — AWS Generative AI Developer Professional Guide 2026](https://flashgenius.net/blog-article/aws-certified-generative-ai-developer-professional-the-complete-2026-ultimate-guide)

### 5. SC-500 Cloud and AI Security Engineer Associate：学习指南 7月11日上线

**一句话**：SC-500 正式学习指南于 2026年7月11日发布，AZ-500（Azure Security Engineer Associate）8月31日退役倒计时不足 5 周，准备走 Azure 安全路线的必须做选择了。

Microsoft 正式发布 **SC-500（Cloud and AI Security Engineer Associate）** 官方学习指南（2026年7月11日），是 AZ-500（Security Engineer Associate，2026年8月31日退役）的继任认证。

**SC-500 vs AZ-500 的核心差异**：

- AZ-500 覆盖：Azure 网络安全、IAM、数据保护、监控（Sentinel/Defender）
- SC-500 新增：**AI 管道安全**——包括 Azure AI Service 的防护策略、AI workload 的权限边界、生成式 AI 输出的安全合规管控

也就是说，SC-500 不只是更名，而是把"AI 安全"塞进了原本的云安全体系，考试难度相应提升。

**时间节点**：
- **2026年7月11日**：SC-500 官方学习指南发布
- **2026年8月31日**：AZ-500 退役

如果你手上有 AZ-500 学习计划，现在建议先确认自己是赶着在 8月31日前考 AZ-500、还是直接转 SC-500——两条路都有人走，但方向要定清楚。
