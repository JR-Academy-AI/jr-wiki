## 一、认证动态

### 1. AWS Advanced Networking Specialty（ANS-C01）今日正式退役

**一句话**：AWS 网络专家认证今天（8 月 25 日）是最后一天可以参加考试，且 AWS 没有推出任何替代认证。

2022 年 7 月替换掉 ANS-C00 的 ANS-C01，成为了这条产品线的终点——AWS 没有宣布 ANS-C02。官方的说法是，想继续深耕网络方向的学员，应转向 [AWS Skill Builder](https://skillbuilder.aws/) 上的数字化培训内容，而不是追求一张新的纸质证书。

**已持有证书的学员**：不受影响，已考取的 ANS-C01 在原始有效期（三年）内照常有效，可正常续期。

**正在备考的学员**：今天是最后机会。8 月 26 日起该考试在全球 Pearson VUE 考场关闭，不再接受预约或赴考。错过了就真没了——没有延期窗口，也没有过渡性考试可以补考。

**对 JR 学员的实操建议**：如果你的 AWS 路线图里原本打算考 ANS-C01，现在需要重新规划。目前 AWS 网络相关的可考路线包括 SAP-C02（Solutions Architect Professional，内含大量网络架构题）以及 Skill Builder 上的「Advanced Networking on AWS」数字课程。职位描述里对"AWS 网络认证"的要求未来将发生漂移，建议先巩固 SAA-C03，再根据 JD 实际要求决定后续方向。

> 来源：[AWS Advanced Networking Specialty Retires 25 August 2026 — CertCrush](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026) · [Your AWS networking hiring screener disappears in August — Substack](https://jrodrigues.substack.com/p/your-aws-networking-hiring-screener)

### 2. AZ-500 六天后退役，SC-500 已上线——Azure 安全认证代际切换

**一句话**：AZ-500（Azure Security Engineer Associate）将于 **2026 年 8 月 31 日** 永久关闭，新考 SC-500 才是今后 Azure 安全方向的入场券。

这次不是小改版，是彻底的代际替换：

| 对比项 | AZ-500 | SC-500 |
|---|---|---|
| 正式名称 | Azure Security Engineer Associate | Cloud and AI Security Engineer Associate |
| 退役 / 上线 | 2026-08-31 退役 | 2026-07-21 GA 上线 |
| Beta 开放 | — | 2026-05-15 |
| 核心覆盖 | Azure 身份、网络、数据、平台安全 | Azure 安全 **+ AI 工作负载安全**（模型环境、Prompt Injection 防御、AI 供应链安全） |
| 证书互认 | — | **不能**自动从 AZ-500 转换，需重考 SC-500 |

**没有"免费升级"也没有"等效声明"**。Microsoft 官方明确：AZ-500 持证者不会被自动颁发 SC-500，现有证书照常有效至到期日，但 SC-500 认证代表的是新的能力图谱，需要独立参加考试。

如果你现在正在备考 AZ-500，剩下 6 天是否值得冲刺？建议直接备考 SC-500——AI 安全内容是未来 2-3 年安全岗位的核心需求，SC-500 的含金量更长久。SC-500 考试在 [Microsoft Learn 官方页面](https://learn.microsoft.com/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/) 可以报名，考试费用与其他 Associate 级别认证相同，请以官网实际价格为准。

> 来源：[AZ-500 Retires August 31, 2026: SC-500 Replaces It — Training Camp](https://trainingcamp.com/articles/az-500-retires-august-31-2026-sc-500-replaces-it-2/) · [AZ-500 Is Retiring August 31, 2026 — DailyDebian](https://dailydebian.com/blogs/it-certification-news/az-500-is-retiring-on-august-31-2026-heres-your-sc-500-transition-plan)

### 3. AZ-802 本月上线：一张证书替代 AZ-800 + AZ-801

**一句话**：Microsoft 把 Windows Server Hybrid Administrator 的两门考试（AZ-800 + AZ-801）合并成一门 AZ-802，预计本月正式开考，两门旧考试 9 月 30 日退役。

AZ-802 针对的是管理本地与 Azure 混合 Windows Server 环境的 IT Pro——服务器管理、混合 AD、Azure Arc、混合存储、灾难恢复都在考试范围内。

关键时间线：
- **2026 年 7 月**：AZ-802 Beta 考试开放
- **2026 年 8 月**：培训材料 + 正式考试预期上线（本月内）
- **2026 年 9 月 30 日**：AZ-800、AZ-801 同步退役

对于已经持有 AZ-800 + AZ-801 证书的学员：两张证书都在有效期内，不需要立刻去考 AZ-802。对于还没有这两张证书的备考者：建议直接转向 AZ-802，一次考试拿同等的资质认定，效率更高。

> 来源：[New AZ-802 Exam Replaces AZ-800 and AZ-801 — CertQueen](https://www.certqueen.com/news_New_AZ-802_Exam_Replaces_AZ-800_and_AZ-801_Retire_on_September_30_2026_5398.html) · [Microsoft Beta Exams 2026 Timeline — MsCertQuiz](https://mscertquiz.com/blog/new-microsoft-beta-exams-2026)

## 二、免费 / 限免课程

### 1. Hugging Face Agents Course（免费，5 单元结构）

**适合**：想系统学 AI Agent 框架的开发者，特别是用过 Transformers 基础、想进阶到生产级 Agent 部署的 Python 开发者

**链接**：[https://huggingface.co/learn/agents-course](https://huggingface.co/learn/agents-course)

这门课是目前 AI Agents 领域最系统、最免费的学习路径之一。5 个单元从零到生产：第 1 单元讲 Agent 概念与 LLM 工具调用基础；第 2、3、4 单元分别深入 LangGraph、LlamaIndex、smolagents 三个主流框架；最后一个 bonus 单元专讲可观测性（observability）与评估（evals）——这正是从玩具项目到生产部署必须补上的最后一块。

全程免费，无需信用卡，完成后有 Hugging Face 的课程证书。对于正在准备 AI/ML 相关技术面试的同学，smolagents 和 LangGraph 在 2026 年的澳洲 IT 招聘 JD 里出现频率明显上升。

## 三、JR Academy 学员行动建议

1. **今天还没考 ANS-C01 的**：这张考卷今天就关闭了，不存在"下周再考"的选项。如果 AWS 网络是你的核心方向，本周把 SAA-C03 排进备考表——网络架构内容仍然在 SAA 里有大量覆盖。

2. **正在备考 AZ-500 的**：六天后关闭，不值得为这张旧卷子赶工。本周把备考资料切换到 SC-500，Microsoft Learn 上已有完整的免费学习路径：[SC-500 学习路径](https://learn.microsoft.com/en-us/credentials/certifications/cloud-and-ai-security-engineer-associate/)。
