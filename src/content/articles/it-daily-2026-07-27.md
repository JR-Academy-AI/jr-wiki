## 一、认证动态

### 1. AZ-204 四天后退役，AI-200 正式 GA 接班

**一句话**：7月31日是最后一天，AZ-204 的考试码永久失效，Azure 开发者认证从此只有 AI-200 这条路。

**AZ-204（Developing Solutions for Microsoft Azure）** 将于 **2026年7月31日正式退役**，无缓冲期。替代认证是 **AI-200：Developing AI Cloud Solutions on Azure**，认证头衔为 **Microsoft Certified: Azure AI Cloud Developer Associate**，已于2026年7月正式 GA（Beta 于5月开放）。

AI-200 的考域与 AZ-204 有明显差异，不是原地升级，而是方向性转型：

- **容器化计算**（containerized compute）
- **向量数据库**（vector-enabled databases）
- **事件驱动 AI 流水线**（event-driven AI pipelines）
- **无服务器函数**（serverless functions）
- **Azure 上的 RAG 架构**（retrieval-augmented generation on Azure）

换言之，原来 AZ-204 考的是通用 Azure 开发（App Service / Azure Functions / CosmosDB / Key Vault），AI-200 的重心转向了 AI 应用开发场景——你需要知道怎么把 Azure OpenAI、Azure AI Search、Azure Container Apps 组合成一个完整的 AI 工作流。

**还在备考 AZ-204 的同学行动参考**：

- 7月31日前有场次且能考：去考，不要浪费已经刷过的题库
- 还没开始、只有4天：不建议仓促备考，直接切 AI-200 准备材料
- 已经计划今年考 Azure 开发路线：目标 AI-200，原 AZ-204 备考材料只有约40%可复用

### 3. AWS ANS-C01 高级网络专项 8月25日最后一天

**一句话**：AWS 五年内连退五张 Specialty 证，ANS-C01 是最后一张，8月25日之后这个认证级别彻底消失。

**AWS Certified Advanced Networking - Specialty（ANS-C01）** 将于 **2026年8月25日正式退役**，这是 AWS 专项认证整合浪潮的收尾：

| 退役时间 | 认证 |
|---------|------|
| 2024年4月 | Database Specialty, Data Analytics Specialty |
| 2024年4月 | SAP on AWS Specialty |
| 2026年3月 | Machine Learning Specialty |
| **2026年8月25日** | **Advanced Networking Specialty（ANS-C01）** |

五张 Specialty 全退，AWS 认证体系向 Professional 级别（SAP-C02 / DOP-C02）和新 AI 路线（AIP-C01 Generative AI Developer Professional）集中。

ANS-C01 考纲覆盖 VPC 架构、Transit Gateway、Direct Connect、混合网络、全球加速、CDN 等 AWS 网络深度内容，考试费 **$300 USD**，通过后证书有效期3年。

已持有 ANS-C01 的同学：证书在到期日前有效，不受退役影响。还没考但有需求的：剩30天，有时间就冲。
