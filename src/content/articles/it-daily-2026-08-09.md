## 一、认证动态

### 1. AZ-800 / AZ-801 九月底双双停考：AZ-802 合并考接棒，已持证者可用续证评估更新

**一句话**：Microsoft AZ-800（Administering Windows Server Hybrid Core Infrastructure）和 AZ-801（Configuring Windows Server Hybrid Advanced Services）将于 2026 年 9 月 30 日 17:00 CST 正式停考，单一合并考 AZ-802「Administering Windows Server Hybrid Infrastructure」接棒，已持完整 Windows Server Hybrid Administrator Associate 证书者可通过 AZ-802 续证评估更新，无需重考全卷。

这是微软 2026 年认证路线中规模最大的 Windows Server 认证整合动作：此前拿到 Windows Server Hybrid Administrator Associate 需要分别通过 AZ-800 和 AZ-801 两门考试，备考时间通常超过 3 个月、两次考试费用合计约 $330（每门 $165）。AZ-802 把两门合并为一门，考试内容覆盖 AZ-800 的 Hybrid Core Infrastructure（AD DS 管理、Azure Arc、Azure Stack HCI）和 AZ-801 的 Hybrid Advanced Services（安全加固、灾难恢复、混合迁移）。

**关键日期与操作要点：**
- **AZ-800 / AZ-801 最后考试日**：2026 年 9 月 30 日，17:00 CST（北京时间 10 月 1 日 06:00）
- **AZ-802「Administering Windows Server Hybrid Infrastructure」**：Beta 阶段已开放报考，正式 GA 预计年底前
- **已持 Windows Server Hybrid Administrator Associate 者**：Microsoft 确认可使用 AZ-802 续证评估（renewal assessment）更新现有证书，无需从头重考完整 AZ-802
- **仅持 AZ-800、尚未考 AZ-801 者**：在 9 月 30 日前补考 AZ-801 完成组合，或直接切换至 AZ-802（Beta 阶段报名费通常低于正式定价，具体以官方当前页面为准）
- **从零开始者**：AZ-802 是更简洁的路径——一门考试拿到同等认证，且合并后的考题包含更多 Hybrid 场景实操题型

**给学员的建议：** Windows Server 方向现在有两个务实的窗口期——① 9 月 30 日前：AZ-801 题库已很成熟、Pass Rate 有参考价值，适合进度过半的学员冲刺完成；② AZ-802 Beta：适合刚开始准备的人，Beta 阶段考过后成绩需等官方评分（约 6-8 周），但不影响最终取证时效。

### 2. Snowflake COF-C02 全面退场，COF-C03 成唯一通路：Cortex AI、Iceberg、Notebooks 四大新考点

**一句话**：Snowflake SnowPro Core COF-C02 英文版已于 5 月 14 日停考，多语言版本于 7 月 31 日全部退场，COF-C03（2026 年 2 月 16 日上线）成为唯一报考路径；新增 Cortex AI、Apache Iceberg、Snowflake Notebooks、Git 集成四大全新考点，考域从 6 个精简为 5 个，题量维持 100 题。

对正在备考 Snowflake 的数据工程师来说，这次更新不只是"换版本"，而是**考试方向的实质性转变**：COF-C02 主要考传统数仓操作（Virtual Warehouse 配置、Snowpipe 加载、RBAC 权限管理等），COF-C03 在这基础上新增了 **AI 数据产品化能力（Cortex AI）** 和**开放表格格式（Apache Iceberg）**。简单说——以前考"怎么建仓、怎么查数"，现在还要考"怎么在 Snowflake 上跑 AI 模型、怎么连接 Iceberg 格式数据源"。

**COF-C02 vs COF-C03 关键变化对比：**

| 项目 | COF-C02（已退场） | COF-C03（当前唯一版本） |
|------|----------|------------|
| 考域数量 | 6 个 | 5 个（精简合并） |
| 题量 | 100 题 | 100 题（不变） |
| AI 考点 | 无 | **新增 Snowflake Cortex AI** |
| 表格格式 | Snowflake 原生 | **新增 Apache Iceberg** |
| 开发工具 | 无 | **新增 Snowflake Notebooks + Git 集成** |

**COF-C02 完整退场时间线（供参考）：**
- 2026 年 2 月 16 日：COF-C03 英文版上线
- 2026 年 4 月 15 日：COF-C03 多语言版上线
- 2026 年 5 月 14 日：COF-C02 英文版停考
- **2026 年 7 月 31 日：COF-C02 多语言版全部停考**（现已完成，无任何 COF-C02 版本仍可报考）

**备考注意点：** 如果你正在使用 Udemy 课程、Anki 题库或旧版 Practice Test，立即检查内容是否涵盖 Cortex AI、Apache Iceberg 相关题目——没有的就是 COF-C02 旧版，需要换成 COF-C03 对应资料。市面上仍有部分旧版题库在流通，认准有"Cortex AI"或"Iceberg"考点的版本才是 C03 考纲。

**报考入口：** [snowflake.com/certifications](https://www.snowflake.com/certifications/)（官方 COF-C03 Exam Guide 可在此免费下载，10 分钟读完，对齐新五大考域）

### 3. Microsoft Partner 认证三合一：Analytics Specialization 本月完成合并

**一句话**：Microsoft 于 2026 年 8 月初将三个独立的合作伙伴 Specialization——Analytics on Microsoft Azure、Data Warehouse Migration to Microsoft Azure、Business Intelligence——合并为单一的新版「Analytics on Microsoft Azure Specialization」，主要影响需要维护 Microsoft 合作伙伴身份的机构，个人考试路径不受影响。

这一变化主要作用于持有 **Microsoft Solution Partner for Data & AI** 或 **Analytics 相关 Specialization** 的企业合作伙伴。如果你所在机构需要满足 Microsoft Partnership 的技术要求，需确认新版 Analytics Specialization 的评估内容是否与你现有的 Specialization 标签对应。

对**个人学员**而言，这次变化影响较小：DP-300（Azure Database Administrator）、DP-600（Fabric Analytics Engineer）、DP-900（Azure Data Fundamentals）等个人认证考试路径维持不变，合并的是 Partner 层级的 Specialization 标签，不是任何一门具体考试。如果你在备考数据方向的 DP 系列，今天可以继续按原计划推进。

### 2. AWS Lab Maker：自然语言生成实操 Lab，Skill Builder Team 订阅者立即可用

**适合**：持有 AWS Skill Builder **Team 订阅**（企业/机构账户）的备考者和工程师

**链接**：[aws.amazon.com/training/digital/immersive-learning](https://aws.amazon.com/training/digital/immersive-learning/)

AWS 于 2026 年 5 月在 Skill Builder 上线了 Lab Maker——一个 AI 驱动的即时实验室生成工具。核心操作：**用自然语言描述你想构建的场景**，Lab Maker 自动生成逐步指导，覆盖在模拟 AWS Management Console 环境里的完整操作步骤。

**使用场景举例：**
- "帮我搭一个用 Amazon Bedrock 调用 Claude 的 Python API，包含 retry 逻辑"
- "给我一个 S3 + Lambda event notification 的 Step-by-step Lab"
- "演示 IAM Role 最小权限原则配置：Condition Key 用法"

每个 Lab 在真实 AWS 沙箱环境里运行，不需要配置本地环境，不需要提前下载资料。对备考 SAA-C03 / DVA-C02 / MLA-C01 的学员来说，这是一个**按考点生成配套动手练习**的高效工具——早上复习哪个考域，下午就能生成对应场景练一遍，不再靠翻文档或找旧版 Lab 将就。

**访问限制：** Lab Maker 目前仅对 AWS Skill Builder **Team 订阅**（企业/机构账户）用户开放，个人 Individual 订阅（$29/月）暂不支持 Lab Maker 功能。如果你的雇主有 AWS Partner Network 账户或企业培训预算，可以向 IT 或 HR 部门申请 Team 账户访问权限——成本通常可以走培训报销。

## 三、JR Academy 学员行动建议

1. **Windows Server 方向：今天查一下自己的 AZ-800/AZ-801 进度。** 9 月 30 日停考，距今约 7 周。进度过半的学员赶 AZ-801 完成组合；刚开始的学员直接上 AZ-802 Beta（一门搞定）。Beta 报名入口在 Microsoft Learn，搜"AZ-802"找到后查看当前 Beta 价格（通常低于正式定价）。

2. **正在备考 Snowflake 的学员：立刻检查资料版本。** 打开你的 Udemy 课程或 Anki 题库，找"Cortex AI"或"Iceberg"关键词——没有就是旧版 COF-C02 资料，需要换掉。到 [snowflake.com/certifications](https://www.snowflake.com/certifications/) 下载 COF-C03 官方 Exam Guide，免费且 15 分钟内能对齐新五大考域。
