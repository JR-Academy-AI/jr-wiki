## 一、认证动态

### 1. AWS ANS-C01 倒计时 18 天：8 月 25 日永久退场，官方确认无接班考试

**一句话**：AWS Advanced Networking Specialty 考试最后一天是 2026 年 8 月 25 日，AWS 官方确认不设 ANS-C02，网络专项认证从此从 AWS 认证体系中消失。

AWS Certified Advanced Networking – Specialty（考试代码 ANS-C01）是目前 AWS 认证体系里考验最深的网络考试，涵盖混合网络、Direct Connect、Transit Gateway、网络安全架构等内容。这门考试的退场并非被升版取代，而是 AWS 主动从认证路径中移除。

**具体数字**：
- 最后考试日：**2026 年 8 月 25 日**（距今 18 天）
- AWS 官方替代方案：无（AWS 方向是 AWS Skill Builder 上的网络数字培训，不设续任考试）
- 已持证者：三年有效期不受影响，到期前照常有效

**对 JR 学员的意义**：如果你已经在备考 ANS-C01，或者打算用这张证书证明网络架构能力，这是最后窗口。错过 8 月 25 日，以后就没机会拿这张证了。如果你还没开始备考，18 天对非系统准备的人来说基本来不及，建议转战 SAP-C02（Solutions Architect Professional）或 DVA-C02 等仍在更新的方向。

> 来源：[certcrush.app — AWS Advanced Networking Specialty Retires 25 August 2026](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026) / [empirikon.co.uk — AWS is retiring the Networking cert, but the Network isn't getting simpler](https://empirikon.co.uk/blog/aws-network-specialist-cert-retired)

### 2. AWS MLA-C01 考纲升版：Beta（MLA-C02）9 月 1 日开报，加入 Agentic AI 和基础模型

**一句话**：AWS 机器学习工程师认证全面升版，MLA-C02 Beta 9 月 1 日起开放英文报名，考题加入 Gen AI / Agentic AI / LLM workloads，Beta 考试 $75，MLA-C01 英文版最后考试日是 9 月 28 日。

AWS Certified Machine Learning Engineer – Associate 是 2024 年末推出的相对新考试，代号 MLA-C01。AWS 于 2026 年 7 月 14 日宣布开始升版（详见官方博客），主要驱动力是 ML 工程师的日常工作已经大幅转向生成式 AI 和 Agentic 工作流。

**具体数字（MLA-C02 Beta）**：
- Beta 开报：**2026 年 9 月 1 日**（英文）
- Beta 考试费：**$75 USD**（通常考题未公布正确答案，是用 Beta 成绩校准难度）
- Beta 考试格式：**170 分钟 / 85 题**，仅 Pearson VUE 在线或线下考场
- MLA-C01 最后考试日（英文）：**2026 年 9 月 28 日**
- 正式版 MLA-C02 预计上线：**2027 年初**

**考纲新增内容**：生成式 AI 解决方案实施、基础模型（Foundation Model）和大语言模型（LLM）工作负载、Agentic AI 工作流编排、AI at scale 的运营化。原来 MLA-C01 侧重传统 ML pipeline 的那套，现在要叠加 Gen AI 那一层。

如果你已经持有 MLA-C01，三年有效期不受影响。如果还在备考，9 月 28 日前按 MLA-C01 考纲硬冲仍然有效，或者等 2027 初直接备考 MLA-C02。

> 来源：[aws-news.com — Updates to AWS Certified Machine Learning Engineer – Associate (MLA-C02)](https://aws-news.com/article/2026-07-14-updates-to-aws-certified-machine-learning-engineer-associate-mla-c02)

### 3. Google Cloud 完成 Pearson VUE 迁移，Professional 认证有效期正式缩短为 2 年

**一句话**：Google Cloud 2026 年 2 月底完成全系认证从 Kryterion 迁移至 Pearson VUE，同步确认 Professional 级别认证有效期为 2 年（Associate / Foundational 仍是 3 年）。

2025 年末 Google Cloud 宣布把旗下所有认证考试的交付平台从 Kryterion/Webassessor 切换到 Pearson VUE，迁移于 2026 年 2 月下旬完成。这对学员最直接的影响有两点：

**平台变化**：原来在 webassessor.com 管理预约的，现在统一到 Pearson VUE 官网报名，登录入口在 [certmetrics.com/google](https://cp.certmetrics.com/google/en/login)。

**有效期变化**：
- Professional 级别（PCA、PDE、PMLE 等）：**2 年**有效期
- Associate 级别（ACE、GAIL 基础层等）：**3 年**有效期
- Foundational 级别（Cloud Digital Leader）：**3 年**有效期

为什么 Professional 缩短？Google Cloud 官方的说法是"云服务迭代太快，3 年的内容等不到你续期就已经过时"。对 2024 年或更早拿证的人，请确认自己的证件到期日——之前可能习惯了3年，现在如果是 Professional 级别记得要早半年准备续期。

Google Cloud 同时推出了新的在线续期路径，可以通过 Google Skills renewal path 在线免费续期（前提是认证还在有效期内）。

> 来源：[Google Cloud Certification FAQs](https://support.google.com/cloud-certification/answer/9438208?hl=en) / [Google Cloud Certification Changes 2026](https://www.3university.io/learn/google-cloud-certification-changes/)

### 4. Google Cloud GAIL 认证：$99 / 零技术背景 / 全球持证人极少，非技术岗差异化利器

**一句话**：Google Cloud Generative AI Leader（GAIL）认证费 $99，90 分钟，50–60 道选择题，有效期 3 年，**不要求任何技术背景**，面向产品经理、业务分析师、咨询顾问等非技术岗，全球持证人数极少，含金量正在快速积累。

GAIL 于 2025 年 5 月正式发布，是 Google Cloud 新增的"商业面"AI 认证，与 Professional ML Engineer（技术向）刚好互补。到 2026 年 5 月，LinkedIn 上 GAIL 持证人还只有几千人，而同期 AWS Cloud Practitioner 持证人已超百万——早入场的差异化价值非常明显。

**官方认证页面确认的数字**：
- 考试费：**$99 USD**（含税另计）
- 考试时长：**90 分钟**
- 题目数：**50–60 题**，全选择题
- 有效期：**3 年**
- 语言：英文、日文、西班牙文、葡萄牙文
- 考试方式：Pearson VUE 线上监考或线下考场
- 先决条件：**无**

**考试四大主题**：生成式 AI 基础知识、Google Cloud AI 产品（Gemini Enterprise Agent Platform 等）、提升 Gen AI 输出质量的技术方法、企业采用 Gen AI 的商业战略。

备考资源：Google Cloud Skills Boost 上有免费 Learning Path（路径 ID：1951）覆盖全部考点。

> 来源：[cloud.google.com/learn/certification/generative-ai-leader](https://cloud.google.com/learn/certification/generative-ai-leader)（官方页面已验证）

## 二、免费 / 限免课程

### 1. Hugging Face LLM 完整课程：12 章，全程免费，无广告

**适合**：想系统学习大语言模型实战的开发者，有 Python 基础即可，不需要买任何订阅。
**链接**：[huggingface.co/learn](https://huggingface.co/learn)

Hugging Face 官方出品的 LLM 课程目前共 12 章，内容从 Transformer 架构基础讲到模型微调（SFT / RLHF）和部署，全部免费、无付费门槛、无广告。覆盖 AutoModelForCausalLM、Datasets、Trainer API 等核心 API 实战，每章都有可运行的 notebook。没有证书，但完成后的 notebook portfolio 本身比一张证书更有说服力。适合正在学 ML 或准备备考 MLA-C02 的同学作为补充实操训练。

---

### 2. DeepLearning.AI × Hugging Face 短课系列：smolagents、模型量化等，视频全免费

**适合**：想快速上手 AI agent 开发或模型压缩的工程师，每门课 1–2 小时，无需付费。
**链接**：[deeplearning.ai/courses](https://www.deeplearning.ai/courses)（过滤 Hugging Face 合作课程）

DeepLearning.AI 和 Hugging Face 合作出品了多门短课，视频均免费观看（不需要 Coursera 订阅）：
- **Building AI Agents with smolagents**：用 Hugging Face smolagents 库构建能写代码、执行代码完成复杂任务的 AI agent
- **Quantization with Hugging Face**：用 Transformers 库 + Quanto 库量化任意开源模型，大幅降低显存占用
- **Web Agent 实战课**：训练能导航和操作网页的 AI agent

这类短课是 andrew ng 那套"每门课用几小时精准拿一个实战技能"的产品路线，非常适合已经有基础、想快速补一个技能点的人。

### 3. Harvard CS50：全程免费 + 免费证书，2026 年仍然可以零成本拿到

**适合**：完全没有编程基础想系统学 CS，或者想补一张有份量证书的非 CS 专业学员。
**链接**：[cs50.harvard.edu](https://cs50.harvard.edu)

Harvard CS50（Introduction to Computer Science）是全球报名量最大的 MOOC 之一。虽然在 edX 平台上证书要付费，但在 cs50.harvard.edu 官方网站提交全部作业后，Harvard 本身会颁发**免费证书**，完全不需要掏钱给 edX。

内容覆盖 C、Python、SQL、HTML/CSS/JavaScript，难度曲线友好但真的有挑战性（problem set 不是填答案那种）。如果你正在准备转行 IT 或者需要一张 Harvard 背书的证书放进简历，这是 2026 年性价比最高的路径之一。完成时间因人而异，4–10 周不等。

## 三、JR Academy 学员本周行动建议

1. **ANS-C01 最后冲刺**：还在备考 AWS 网络认证的同学，8 月 25 日之前必须完成报名并考完。现在去 [aws.amazon.com/certification/certified-advanced-networking-specialty/](https://aws.amazon.com/certification/certified-advanced-networking-specialty/) 预约考场，不要拖到 8 月 24 日才发现没有空位。

2. **MLA-C01 vs MLA-C02 选哪个**：如果你已经备考了 MLA-C01 六成以上，趁 9 月 28 日关门前用 MLA-C01 考完，拿到后有效期三年。如果刚开始，可以等 2027 初 MLA-C02 正式版——用 $75 Beta 考纲押宝有风险，Beta 成绩不保证通过。

3. **Google Cloud 持证人检查有效期**：如果你有任何 Professional 级别 GCP 认证（PCA、PDE、PMLE），登录 [certmetrics.com/google](https://cp.certmetrics.com/google/en/login) 确认到期日。如果是 2024 年或更早拿的，今年就可能要续期了，Pearson VUE 体系下续期流程和以前不同，提前熟悉。

4. **非技术岗考 GAIL 的时机**：$99、90 分钟、不要求技术背景——如果你是产品经理、业务分析师、或正在转型 AI 方向的顾问，现在入手 GAIL 是差异化窗口最大的时候（全球持证人数仍然很少）。备考路径：Google Cloud Skills Boost 路径 1951，全免费。

5. **刷完 Hugging Face LLM 课前两章**：这周把 HF LLM 课第 1–2 章的 notebook 跑一遍，上手 Transformer 基础和 AutoModelForCausalLM。如果在备考 MLA-C02，这些概念直接对应考纲里的基础模型知识点。
