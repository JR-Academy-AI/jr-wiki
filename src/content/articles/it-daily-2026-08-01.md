## 一、认证动态

### 1. AZ-500 本月底退场：30 天倒计时，直接备考 SC-500 还是趁早卡最后一次？

**一句话**：Azure Security Engineer Associate（AZ-500）将于 **2026 年 8 月 31 日**永久停考，接班者 SC-500（Cloud and AI Security Engineer Associate）报考费 **$165 USD**，新增 AI 安全完整子域，无任何自动转换通道。

AZ-500 是 Azure 安全方向的核心认证，多年来是澳洲云安全岗位最受认可的证书之一。但从 **2026 年 8 月 31 日**起，这门考试关闸，新考生只能走 SC-500 这条路。

**关键区别对比：**

| 项目 | AZ-500（停考中） | SC-500（接替） |
|------|---------------|--------------|
| 最后报名 | 2026 年 8 月 31 日 | 现在可报 |
| 报考费 | 约 $165 USD | **$165 USD** |
| 考试时长 | 150 分钟 | **120 分钟** |
| 通过分数 | 700/1000 | **700/1000** |
| 题目数量 | 40-60 题 | **50-60 题** |
| 新增领域 | — | Copilot 安全防护、Azure OpenAI 部署安全、Microsoft Entra Agent ID、Foundry AI 代理防护 |

SC-500 保留了 AZ-500 的核心内容：Defender for Cloud、Microsoft Sentinel、身份保护、零信任网络架构。但它额外增加了整个 **AI 安全子域**——如何保护 Copilot 部署、如何在 Azure OpenAI 环境里实施访问控制、如何用 Purview 管理 AI 数据合规、以及 Microsoft Entra Agent ID 的智能体身份管理。这些内容在 AZ-500 里完全不存在。

另一个变化：SC-500 的部分新任务需要在 Purview 和 M365 Admin Center 里操作，而不是在 Azure Portal 里——这对习惯了纯 Azure Portal 操作的 AZ-500 备考者是个认知跃迁。

**没有自动转换**：持有 AZ-500 证书的人，证书继续有效至原到期日。但到期续证时，续考路径是 SC-500 的续考评估（renewal assessment），不是重考完整 SC-500。

**30 天倒计时建议：**
- 还没开始考、刚刚入门 Azure 安全 → 直接备考 SC-500，新考纲更贴合 2026 年岗位实际
- 已经备考 AZ-500 超过 2 个月、刷题刷了一半 → 可以在 8 月 31 日前抢考，但要评估 30 天内能否稳过 700
- 已持有 AZ-500 → 证书继续有效，到期再走续考路径，不用现在做任何事

### 2. AZ-800 + AZ-801 合并为单考 AZ-802：Windows Server 双证时代 9 月结束

**一句话**：Windows Server Hybrid Administrator Associate 的两门入场考试（AZ-800、AZ-801）将于 **2026 年 9 月 30 日**正式退场，由单门考试 **AZ-802** 接替，七大考域范围不变，但只用考一次。

目前拿 Windows Server Hybrid Administrator Associate 认证需要通过 AZ-800（Administering Windows Server Hybrid Core Infrastructure）和 AZ-801（Configuring Windows Server Hybrid Advanced Services）两门考试。从 **2026 年 9 月 30 日**起，这条双考路径关闭。

**AZ-802 的七大考域：**
1. Active Directory Domain Services 管理
2. Windows Server 与混合工作负载
3. 虚拟机管理
4. 本地与混合网络
5. 存储与文件服务
6. Windows Server 安全
7. 监控与故障排查

七个域与原 AZ-800/AZ-801 合并范围基本对齐，没有新增内容，是名副其实的"合并瘦身"。

**对现有考生的影响：**
- 已持有 AZ-800/AZ-801 认证 → 到期续证时可以用 **AZ-802 续考评估**，无需重考完整 AZ-802
- 还没考、或只过了其中一门 → 尽快决策：9 月 30 日前用 AZ-800+AZ-801 原路走完，或者切换到 AZ-802 单考路径（目前 AZ-802 处于 beta 阶段）
- beta 考试通常比正式版便宜 30–40%，适合早鸟

> 来源：[AZ-800 and AZ-801 Retire September 30, 2026 — Choose AZ-802](https://windowsforum.com/windows-news.4/az-800-and-az-801-retire-september-30-2026-choose-az-802.439219/) · [New AZ-802 Exam Replaces AZ-800 and AZ-801 – CertQueen](https://www.certqueen.com/news_New_AZ-802_Exam_Replaces_AZ-800_and_AZ-801_Retire_on_September_30_2026_5398.html)

### 3. Google Cloud 证书续证新路径：2026 年 7 月起可用 Google Skills 徽章替代重考

**一句话**：Google Cloud 从 2026 年 7 月起为 PCA、PDE、ACE、CDL 持有者新增第三种续证方式——完成指定 Google Skills 课程或技能徽章即可续证，无需重考；2026 年 1 月 1 日至 8 月 31 日内到期的证书获得一次性延期至 **2026 年 9 月 1 日**。

原来 Google Cloud 专业认证续证只有两种选择：重考完整考试，或者通过一个较短的续考（renewal exam）。从 2026 年 7 月开始，持有以下认证的考生多了第三选项：

- **Professional Cloud Architect（PCA）**
- **Professional Data Engineer（PDE）**
- **Associate Cloud Engineer（ACE）**
- **Cloud Digital Leader（CDL）**

新路径：在 **Google Skills**（[skills.google](https://www.skills.google)）平台上完成指定课程或技能徽章，可替代续考，让证书续期。对于忙于工作、不想花时间刷题备考的在职工程师来说，这是实质性的便利。

**延期窗口：** 如果你的上述四项认证在 **2026 年 1 月 1 日至 8 月 31 日**之间到期或即将到期，Google 提供一次性延期至 **2026 年 9 月 1 日**，专门为了给考生时间体验新的 Google Skills 续证路径。

另一个值得注意的变化：Google Cloud 考试已从 Kryterion 迁移至 **Pearson VUE**，考场选择和排期灵活性有所提升，同时 Associate Cloud Engineer（ACE）的考试大纲新增了 GKE Autopilot 管理、主动成本优化建议、Gemini 辅助云运维等内容。

> 来源：[Google Cloud Certification Exam Updates – July 2026](https://www.testpreptraining.ai/blog/google-cloud-certification-exam-updates/) · [Google Cloud Changed Exam Delivery and Renewal Rules in 2026 – DailyDebian](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)
