## 一、认证动态

### 1. Databricks 推出全球首个 Context Engineer 认证，$200 已开考

**一句话**：全球首个专门验证 AI agent 上下文管理与 RAG 设计能力的认证，7 月 29 日第一场已开考，现在就能报名。

Databricks 将"context engineering"定义为 agentic AI 系统能否可靠运行的关键能力——包括如何设计 retrieval pipeline、管理多轮对话的上下文窗口、以及保证 agent 行为可观测、可审计。这张认证（**Databricks Certified Context Engineer Associate**）就是在验证这套技能。

考试规格：

- **价格**：$200 USD
- **时长**：90 分钟，约 45 道评分题
- **形式**：在线监考（online proctored）
- **有效期**：2 年
- **开考日期**：2026 年 7 月 29 日（第一批已开考）

对 JR 学员的意义：这是目前市面上极少数专门考 RAG / context window / agent memory 设计的厂商认证，而不是泛泛的"AI 基础"。如果你在学 Databricks 数据工程或 GenAI Engineering 方向，这张卡本月就可以排进备考计划。

> 来源：[Databricks 官方博客 — Context Engineer Associate 认证发布](https://www.databricks.com/blog/databricks-context-engineer-associate-industrys-first-certification-reliable-ai-agent-systems)

---

### 2. 微软 8 月 31 日双退场：AZ-500 → SC-500，PL-200 → AB-410

**一句话**：两张老卷 8 月底同步退役，替代卷都已开放报名，现在还有机会赶考一张老卷或直接转新卷。

**AZ-500 → SC-500（云与 AI 安全工程师）**

Azure Security Engineer Associate（AZ-500）于 **2026 年 8 月 31 日** 正式退役。接棒的是 **Cloud and AI Security Engineer Associate（SC-500）**，已于 7 月 21 日开放考试。SC-500 在传统云安全覆盖范围上新增了 AI 工作负载安全内容，符合当前企业部署 AI 系统对安全角色的新要求。考试价格与 Microsoft Associate 级别对齐（通常 $165，具体以 Pearson VUE 报名页为准）。

如果你 AZ-500 备考已经进入尾声，8 月 31 日前完成考试，认证仍然有效 1 年（不受退场影响）。

**PL-200 → AB-410（智能应用构建者）**

Power Platform Functional Consultant Associate（PL-200）同样于 **8 月 31 日** 退役，替代卷是 **Intelligent Applications Builder Associate（AB-410）**，已于 7 月 30 日开放考试。AB-410 聚焦在用 Power Platform + AI Builder + Copilot Studio 构建智能应用的实操技能，比老卷更贴合当前的 Microsoft 365 Copilot 生态。注意：AB-410 早期 Beta 折扣（6 月 17 日前 8 折）已过期，目前按正常价报名。

> 来源：[Microsoft 2026 年认证退场综合整理](https://www.aicloudpartners.com/guides/microsoft-certification-retirements-2026.html)

### 3. AZ-802 本月 GA：一张卷合并 AZ-800 + AZ-801，老卷 9 月 30 日退场

**一句话**：Windows Server 混合管理员认证路径大调整——两张老卷合并成一张 AZ-802，本月正式开考，9 月底前仍可考老卷。

微软宣布将 **Microsoft Certified: Windows Server Hybrid Administrator Associate** 重命名为 **Microsoft Certified: Windows Server Administrator Associate**，同时把原来的两张考卷：

- Exam AZ-800（管理 Windows Server 混合核心基础设施）
- Exam AZ-801（在混合环境下配置 Windows Server 高级服务）

合并成一张 **Exam AZ-802: Administering Windows Server**。

时间线：
- Beta 考试：2026 年 6 月上线
- **GA（正式开考）：2026 年 8 月**
- AZ-800 和 AZ-801 退役日期：**2026 年 9 月 30 日**

对于已经在备考 AZ-800/AZ-801 的学员：9 月 30 日前还可以考两张老卷拿认证；但如果才刚开始，直接报 AZ-802 更省时间（一卷搞定，不用两次考试费）。

> 来源：[Microsoft 技术社区博客 — AZ-802 新考试公告](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-exam-for-microsoft-certified-windows-server-administrator-associate-certific/4494120)

### 4. Anthropic 官方认证落地 Pearson VUE，但有一道门槛

**一句话**：4 张 Anthropic 官方认证 7 月 23 日正式上线 Pearson VUE，$99–$175，但目前仅限 Claude Partner Network 成员公司的员工才能报考。

认证体系详情：

| 考试名 | 代码 | 价格 | 时长 |
|---|---|---|---|
| Claude Certified Associate | CCAO-F | $99 | 120 分钟 |
| Claude Certified Developer | CCDV-F | $125 | 120 分钟 |
| Claude Certified Architect (Foundations) | CCAR-F | $125 | 120 分钟 |
| Claude Certified Architect (Professional) | CCAR-P | $175 | 120 分钟 |

所有考卷满分 1000，通过线 720，通过 Pearson VUE 在线监考或实体考场作答。

**重要门槛**：截至 2026 年 8 月，考试注册要求使用**所属公司的企业邮箱**，且该公司必须是 Anthropic Claude Partner Network 成员。独立开发者、自由职业者、或公司不在合作伙伴名单内的学员目前无法报名。如果你的公司已是 AWS/Azure/GCP 合作伙伴，值得确认是否也有 Claude Partner 资格。

> 来源：[Claude 认证全览 — claudepractice.com](https://claudepractice.com/certifications)

**适合**：想系统学 Claude API / Claude Code / MCP / 多智能体的开发者，目标 Anthropic 认证或 AI 工程岗位
**链接**：[https://www.anthropic.com/learn](https://www.anthropic.com/learn)

Anthropic Academy 目前收录 18 门课程，全部免费，完成后颁发结业证书（区别于 Coursera 版本——Academy 版含证书）。课程覆盖：

对比 Pearson VUE 的 Anthropic 官方认证（需要合作伙伴邮箱），Academy 证书对大多数学员是更实际的首选——没有入门门槛，有真实学习路径可以跟。

### 3. Google Cloud Skills Arcade 2026：7 月场进行中，免费拿 Skill Badge

**适合**：想在简历上加 Google Cloud 技能徽章、或备考 GCP Associate Cloud Engineer 的学员
**链接**：[https://cloudskillsboost.google](https://cloudskillsboost.google)

Google Cloud Skills Arcade 是 Google 全年持续运行的免费 gamified 学习计划——完成指定 Qwiklabs 实操 + 通过 Challenge Lab，就能拿到可在 LinkedIn 分享的 Skill Badge。7 月场仍在进行中（通常每场持续 4-6 周）。

Skill Badge 与普通 Completion Badge 的区别：Completion Badge 只要完成视频+实操，而 Skill Badge 需要在真实 GCP 环境里独立完成任务（类似小型实战考试）——含金量更高，也更值得写进简历。

> 来源：[Google Cloud Skills Boost 免费徽章目录 — meshworld.in](https://meshworld.in/blog/reference/learning/google-cloud-skills-boost-badges/)
