## 一、认证动态

### 1. GitHub Actions 认证 8 月 7 日改版：英文题库全面更新

**一句话**：Microsoft GitHub Actions 认证英文版将于 **2026 年 8 月 7 日**完成题库更新，正在备考或计划近期参考的同学需要核对新考试技能列表。

GitHub Actions 是目前澳洲企业用得最广的 CI/CD 工具之一，Microsoft 的官方认证考核工作流设计、runner 管理、secret 安全处理和自动化策略。此次更新是 Microsoft 2026 年"AI 时代技能"全线刷新节奏的一部分——和 AZ-500 退役、SC-500 接班同属一个大改革周期。

这次改版对以下人群有直接影响：

- **正在备考**：8 月 7 日之后参考的新版题域可能和旧练习题不完全对应，特别是 Copilot 工作流集成、GitHub Advanced Security 自动化场景的比重可能调整
- **已持证者**：当前证书有效期不变；再次参考时才需按新题域准备
- **购买了第三方题库**的同学：更新后旧题包可能含已下线题目，去官方确认改版内容后再决定要不要补新资料

**实操建议**：直接打开 Microsoft Learn 上的 [GitHub Actions 认证页面](https://learn.microsoft.com/en-us/credentials/certifications/github-actions/)，在"Skills measured"部分看改版后的考域百分比分布，和你现在的备考材料对照，缺口补一补。

> 来源：[Microsoft Learn – GitHub Actions Certification](https://learn.microsoft.com/en-us/credentials/certifications/github-actions/)

### 2. Linux Foundation CARE 计划扩大：过 CKS 可自动续 CKA + KCSA + KCNA

**一句话**：**2026 年 6 月 18 日**起，通过或重认证 CKS（Certified Kubernetes Security Specialist）将自动激活或延续 CKA、KCSA、KCNA 三张证书——哪怕 CKA 已经过期也适用。

这是 Linux Foundation CARE（Certification Advancement and Renewal Experience）计划的最新扩展。之前 CARE 只允许通过高阶考试延续部分低阶证，这次把 CKS 的联动范围扩到了三张：

| 你做的事 | 自动获得的好处 |
|---------|-------------|
| 通过 CKS 考试 | CKA 延续至 CKS 同一到期日 |
| 通过 CKS 考试 | KCSA（Kubernetes and Cloud Native Security Associate）延续 |
| 通过 CKS 考试 | KCNA（Kubernetes and Cloud Native Associate）延续 |
| CKA 已过期 | 同样可以通过 CKS 重新激活 CKA |

**价格**：CKS 和 CKA 标准价均为 **$445 USD**（2025 年 2 月从 $395 调涨），含两次考试机会（第一次不过可免费重考一次）。如需同时包含 THRIVE-ONE 年度订阅（含全部 e-Learning 课程），套餐价 **$625 USD**。

**账是这样算的**：如果你的 CKA 在未来 12 个月内到期，与其花 $445 单独续 CKA，不如直接备考 CKS（同样 $445）——通过 CKS 会自动把 CKA 续期，顺带还拿下 KCSA 和 KCNA 的续期，等于一份考试费联动三张证。

**CKS 备考重点**（2026 年当前考纲）：
- **Falco** 运行时威胁检测
- **OPA/Gatekeeper** 策略执行
- **PodSecurity Admission Controller**（PSP 已彻底废弃，不要再读旧资料）
- **Kubernetes v1.33** 考试环境（含 AppArmor 配置、seccomp profile）
- **Network Policy** 深度多层隔离场景

> 来源：[Linux Foundation – CARE Program](https://training.linuxfoundation.org/care-program/)

### 4. CKA 考纲 2026 更新：Gateway API 入题，告别 Ingress 旧思路

**一句话**：现行 CKA 考试已加入 **Gateway API** 实操题，是比 Ingress 更灵活的下一代流量管理方案，2023 年以前的备考资料需要补这个知识点。

Ingress 多年来是 Kubernetes 七层流量管理的标配，但 Gateway API 的出现从根本上改变了路由规则的设计方式。CKA 考题已经反映了这个演变：

**Gateway API 和 Ingress 的核心区别**：
- **资源分离**：Gateway API 把"基础设施配置"（GatewayClass、Gateway）和"路由规则"（HTTPRoute、TCPRoute、TLSRoute）拆开，让平台团队和应用团队各管各的
- **协议覆盖更广**：Ingress 只支持 HTTP/HTTPS；Gateway API 原生支持 TCP、UDP、TLS passthrough
- **行业趋势**：GKE、EKS、AKS 都已经把 Gateway API 列为默认流量管理方案

**考试实操建议**：
1. 练习创建 `GatewayClass` 和 `Gateway` 资源（配置 listener + port）
2. 编写 `HTTPRoute` 实现路径匹配和权重流量分配
3. 理解 `ReferenceGrant` 跨 namespace 的引用机制

另外，考试环境已是 Kubernetes v1.33，PodSecurityPolicy 已经在 v1.25 彻底删除——如果你的备考资料还在讲 PSP，直接忽略那一章。

> 来源：[CloudInsight – Kubernetes Certification Complete Guide: CKA, CKAD, CKS Exam Preparation 2026](https://cloudinsight.cc/en/blog/kubernetes-certification)  
> 来源：[DEV.to – CKA Exam Report 2026: Don't Rely on Old Guides](https://dev.to/suzuki0430/cka-certified-kubernetes-administrator-exam-report-2026-dont-rely-on-old-guides-mastering-the-534m)
