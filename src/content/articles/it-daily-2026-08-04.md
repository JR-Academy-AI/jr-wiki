## 一、认证动态

### 1. AWS AIF2CLOUD 促销：AIF-C01 打五折，通过后 CLF-C02 免费

**一句话**：用 promo code AIF2CLOUD，把 AWS AI Practitioner 考试费从 $100 砍到 $50，过了之后 Cloud Practitioner 白送一张考试券。

这是 AWS 今年最值得用的一个促销，细节如下：

- **Promo code**：`AIF2CLOUD`（在 Pearson VUE 结账时输入）
- **适用考试**：AIF-C01（AWS Certified AI Practitioner）
- **折后价**：原价 $100 USD → **$50 USD**
- **通过奖励**：自动收到 CLF-C02（AWS Certified Cloud Practitioner）的免费考试券
- **CLF-C02 券使用截止**：**2026 年 11 月 30 日**
- **整个促销有效期**：**2026 年 5 月 26 日 – 9 月 30 日**
- **限制**：每个账号仅可使用一次，不可叠加其他折扣

AIF-C01 考察 AWS AI/ML 服务（SageMaker、Bedrock、Rekognition 等）、GenAI 原理、Responsible AI 框架，以及 AWS 上的 AI 解决方案架构基础，120 分钟 65 题，通过线 700 分。CLF-C02 则涵盖 AWS 核心服务、计费模型和云基础架构，两张证加起来是进 AWS 生态最快的入门组合。

对于还没有任何 AWS 认证的学员：这条路线算是目前最低成本的双证路径。花 $50 考一门，通过后拿第二张免费券，相当于用一张证的价格拿两张。报名在 pearsonvue.com/aws，选 AIF-C01，结账输 AIF2CLOUD 即可。

### 2. 微软推出 DP-750：微软 × Databricks 联名数据工程师认证

**一句话**：DP-750 是微软首张与 Databricks 联名的认证，面向在 Azure 上跑 Databricks 的数据工程师，过线分 700/1000，目前已正式上线。

认证全名：**Microsoft Certified: Azure Databricks Data Engineer Associate**，对应考试 **DP-750: Implementing Data Engineering Solutions Using Azure Databricks**。

考试覆盖三块核心：
1. 用 SQL 和 Python 摄取、转换、建模数据
2. 在 Azure Databricks 上构建生产级数据管道
3. 用 Git 工作流实现 SDLC 实践（CI/CD 部署、版本管理）

- 通过分：**700 / 1000**（注意：Databricks 自己的 Data Engineer Associate 通过线是 70%，两者独立）
- 报名入口：[learn.microsoft.com/credentials/certifications/implementing-data-engineering-solutions-using-azure-databricks](https://learn.microsoft.com/en-us/credentials/certifications/implementing-data-engineering-solutions-using-azure-databricks/)

这张证和 Databricks 官方的 Data Engineer Associate 是两张**完全独立**的认证，拿一张不会自动获得另一张，但内容高度重叠。对于在 Azure 上用 Databricks 的团队，DP-750 比 Databricks 原版认证更容易和 Azure 技术栈认证体系挂钩（和 AZ-900、DP-203 系列放在一起更有说服力）。

> 来源：[New Microsoft Certified: Azure Databricks Data Engineer Associate — Microsoft Tech Community](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-azure-databricks-data-engineer-associate-certification/4494114) | [learn.microsoft.com/credentials](https://learn.microsoft.com/en-us/credentials/certifications/implementing-data-engineering-solutions-using-azure-databricks/)

### 3. Databricks Data Engineer Associate 考纲 5 月 4 日大改：CI/CD 独立成章

**一句话**：5 月 4 日生效的新版考纲把 Databricks DE Associate 从 5 个模块扩到 7 个，三个关键变化：Governance 占比腰斩、Delta Sharing 被删、CI/CD 首次独立成章。

2026 年 5 月 4 日，Databricks 正式上线了 Data Engineer Associate 考试的新版 Exam Guide，主要变动：

| 变化 | 旧版（2025）| 新版（2026-05-04）|
|------|------------|-----------------|
| 模块数 | 5 个 | **7 个** |
| Governance 占比 | ~33% | **15%** |
| Delta Sharing / Lakehouse Federation | 有考 | **已删除** |
| CI/CD | 散落各处 | **独立成章** |
| Lakeflow Jobs | 未单列 | **独立成章** |
| Troubleshooting/Monitoring/Optimization | 未单列 | **独立成章** |

术语也同步更新：
- Asset Bundles → **Declarative Automation Bundles**
- Repos → **Git Folders**

**对备考学员的影响**：2025 年以前的备考资料（尤其是 Udemy 上的旧版题库）已经失去参考价值。Databricks 官网已更新 [官方 Exam Guide PDF](https://www.databricks.com/sites/default/files/2026-03/databricks-certified-data-engineer-associate-exam-guide-may-4-2026.pdf)，备考请以这份 PDF 为准。

考试费仍为 **$200 USD**，通过线 **70%**，全部在线监考，不设笔试中心。

> 来源：[Databricks Data Engineer Associate Exam Guide May 2026 — databricks.com（官方 PDF）](https://www.databricks.com/sites/default/files/2026-03/databricks-certified-data-engineer-associate-exam-guide-may-4-2026.pdf) | [Databricks DE Associate 2026 Syllabus Changes — alexcole.net](https://www.alexcole.net/databricks-data-engineer-associate-2026-syllabus-changes/)

### 4. 微软 PL-200 本月底退场，AB-410 从 7 月 30 日起可报

**一句话**：Power Platform 旧路线 PL-200（Functional Consultant）8 月 31 日退役，替代者 AB-410（Intelligent Applications Builder）已开放报名。

**Power Platform Functional Consultant Associate（PL-200）** 在 **2026 年 8 月 31 日**正式退役，与 AZ-500 同一天。替代认证是 **Exam AB-410: Microsoft Intelligent Applications Builder Associate**，已于 **2026 年 7 月 30 日**开放报名。

这次换代的背后逻辑：微软把 Power Platform 的重心从"无代码业务流程自动化"转向"AI 驱动的智能应用和智能体构建"。AB-410 考察如何使用 Power Platform + Copilot Studio + AI Builder 构建面向业务的 AI 应用，比 PL-200 更侧重 AI 集成和智能体编排。

已持有 PL-200 证书的学员：现有证书按原有效期维持，不影响当前持证状态；但续证时需要转到 AB-410 方向。目前备考 PL-200 的学员：距离考试截止还有 27 天，如果进度超过一半，冲刺考完；不然直接切换 AB-410 备考资料。
