## 一、认证动态

### 1. 倒计时 14 天：AWS 高级网络专项 ANS-C01 八月二十五日永久停考

**一句话**：AWS Certified Advanced Networking – Specialty（ANS-C01）将于 2026 年 8 月 25 日停考，没有继任考试，已持证书的三年有效期正常计算。

AWS 这次退场的是它的第五张 Specialty 级认证——2024 年以来 Database、Data Analytics、SAP、Machine Learning 四张已经先后下架，ANS-C01 是最后一张。停考之后，AWS 官方引导需要学习网络知识的候选人前往 AWS Skill Builder 平台的网络数字训练内容，但并未宣布推出替代考试。

对还没考的同学：14 天内约考依然可行，但如果你才开始备考，报名费约 300 USD、备考周期本来就要几个月，时间上已经不够用，直接跳过、改看 Skill Builder 免费内容是更务实的选择。

对已持证的同学：无需担心。在停考日前通过的证书，仍按照标准的三年有效期计算，不受退场影响。

> 来源：[AWS Advanced Networking Specialty Retires 25 August 2026 – CertCrush](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026)

### 2. AZ-500 八月三十一日退场，SC-500 接棒：Azure 安全认证加入 AI 防御考点

**一句话**：Azure Security Engineer Associate（AZ-500）在 8 月 31 日 11:59 PM CT 正式停考，替代者 SC-500「Cloud and AI Security Engineer Associate」已于 7 月正式 GA。

AZ-500 退场是 Microsoft 2026 年「AI 时代技能重塑」大改革的一部分。新认证 SC-500 在保留 Azure 安全核心考点（身份 / 网络 / 数据 / 平台保护）的基础上，全面加入了 **AI 工作负载安全**：保护 AI 模型运行环境、防御提示注入（Prompt Injection）、管理 AI 供应链风险。Beta 阶段于 5 月 15 日开放，7 月 GA。

**几个关键区别：**

| 维度 | AZ-500（退场） | SC-500（接棒） |
|------|--------------|--------------|
| 覆盖范围 | Azure 安全工程 | Azure + AI 工作负载安全 |
| AI 内容 | 无 | 模型保护、提示注入防御、AI 供应链 |
| 续证方式 | 到期可用续证评估 | 到期可用续证评估（新） |
| 过渡路径 | 无官方等效路径 | 需重新备考 |

Microsoft 明确说明：已通过 AZ-500 的证书继续有效至到期日，不需要立即换考。但如果你还没考 AZ-500、且在 8 月 31 日前不能安排考试，请直接备考 SC-500。

> 来源：[AZ-500 Retires August 31: Choose SC-500 – Windows Forum](https://windowsforum.com/windows-news.4/az-500-retires-august-31-choose-sc-500-for-cloud-security.442028/) · [SC-500 vs AZ-500 – CertCrush](https://www.certcrush.app/blog/az-500-vs-sc-500-which-microsoft-security-cert-2026)

### 3. PL-200 同日停考，AB-410「Intelligent Applications Builder」7 月已上线

**一句话**：Power Platform Functional Consultant Associate（PL-200）8 月 31 日退场，接棒者 AB-410「Intelligent Applications Builder Associate」已于 7 月 30 日正式发布。

这一轮改名不只是换个考代码——考试内容的重心发生了根本转变。

PL-200 考的是传统 Power Platform 功能顾问技能：配置 Microsoft Dataverse、用 Power Apps 建应用、用 Power Automate 做流程自动化、管理 Power Platform 环境。这套技能在 AI Copilot 全面嵌入之前是主流岗位要求。

AB-410 对应的是 2026 年之后真实的 Power Platform 岗位要求：用 Copilot Studio 构建 AI 代理、将 LLM 集成进企业应用、设计 AI-first 的低代码解决方案。考试核心转向 **Copilot 驱动开发 + 智能应用设计**。

如果你已经在备考 PL-200 且能在 8 月 31 日前完成，考完是合理选择（证书仍有效）；如果刚刚开始，直接切换到 AB-410 对长期职业发展更有利。

> 来源：[AB-410 Replaces PL-200 – PassQuestion](https://www.passquestion.com/news/ab-410-replaces-pl-200-microsoft-intelligent-applications-builder-associate-exam-guide.html) · [PL-200 vs AB-410 – CertEmpire](https://certempire.com/pl-200-vs-ab-410/)

### 4. Google Cloud 新增 Skills 续证路径，早期持证人宽限至 9 月 1 日

**一句话**：从 2026 年 7 月起，PCA / PDE / ACE / CDL 持证人可通过完成 Google Skills 课程和 Skill Badge，替代传统的重考续证，宽限期到 9 月 1 日。

这次 Google Cloud 的续证改革主要针对四张核心认证：Professional Cloud Architect（PCA）、Professional Data Engineer（PDE）、Associate Cloud Engineer（ACE）、Cloud Digital Leader（CDL）。新增的第三种续证方式是：在 Google Skills 平台完成指定课程或 Skill Badge，不需要重新预约并参加完整考试。

特别规定：如果你的上述认证在 2026 年 1 月 1 日之后到期，或原本会在 2026 年 8 月 31 日前失效，Google 给出了一次性宽限期，截止日期是 **9 月 1 日**，用新的 Google Skills 路径完成续证即可。

另外一个值得注意的背景：Google Cloud 考试平台在 2026 年 2 月 26 日已从 Kryterion/Webassessor 迁移到 Pearson VUE，报名通道也随之切换。

> 来源：[Google Cloud Changed Exam Delivery and Renewal Rules in 2026 – DailyDebian](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026) · [Google Cloud Certification Exam Updates July 2026 – TestPrepTraining](https://www.testpreptraining.ai/blog/google-cloud-certification-exam-updates/)

## 二、免费 / 限免课程

### 1. AWS Skill Builder — Introduction to AWS Cloud 免费 10 实验室学习计划

**适合**：刚接触 AWS 的零基础学员，或正在备考 AWS Cloud Practitioner 的同学  
**链接**：[AWS Skill Builder](https://explore.skillbuilder.aws/)

AWS Skill Builder 上线了一个全新的免费学习计划「Introduction to AWS Cloud」，包含 10 个 Builder Labs 实操练习，覆盖 Amazon EC2（计算）、S3（对象存储）、Lambda（无服务器）等核心服务。每个 Lab 都提供真实 AWS 环境——不是模拟器，是真实沙盒账号——完成后颁发免费数字证书。

对于还没开始 AWS 学习的同学来说，这是目前零成本上手 AWS 实操的最直接路径，尤其在 ANS-C01 刚刚宣布停考的时机，先从基础打起比追 Specialty 认证更稳。

### 2. Microsoft Learn — SC-500 / AB-410 免费官方学习路径

**适合**：准备备考 SC-500 或 AB-410 的同学，零基础入门 Azure 安全 / Power Platform AI 方向  
**链接**：[Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/)

随着 AZ-500 和 PL-200 的退场，Microsoft 已在 Learn 平台为 SC-500 和 AB-410 配套了完整的免费学习路径。两条路径均包含视频、文字教程、知识检测练习题，全部免费，无需注册付费订阅。

SC-500 的学习路径涵盖 Azure 安全基础、AI 工作负载保护、提示注入攻击理解与防御；AB-410 的路径侧重 Copilot Studio 实操、AI 代理设计、Dataverse AI 集成。两条路径都有官方 Microsoft 认可的学习沙盒，可以直接在浏览器里练习操作。

## 三、JR Academy 学员行动建议

1. **ANS-C01 最后 14 天**：8 月 25 日前还没报名的同学，14 天内很难系统备考，建议放弃这张认证——AWS 网络方向改看 Skill Builder 上的免费网络课程，比强行冲停考认证更值。已约好考位的同学正常应考即可。

2. **Azure 安全方向抉择**：8 月 31 日前能考完 AZ-500 的同学正常考；没开始的同学，现在直接去 Microsoft Learn 开 SC-500 的免费路径，把 AI 安全的新考点一起学进去，对应的岗位描述已经开始要求 SC-500。

3. **Power Platform 方向**：要做 Copilot Studio 和 Power Automate 方向的同学，直接从 AB-410 开始，PL-200 的传统功能顾问定位在现有岗位描述里已经越来越少见。Microsoft Learn 上 AB-410 的免费路径已配套，这周就可以开始看。

4. **Google Cloud 续证最后窗口**：如果你持有 PCA / PDE / ACE / CDL 且证书今年内到期，现在去 Google Cloud Skills Boost 开始刷 Skill Badge，**9 月 1 日宽限期是截止线**，错过就需要重新参加完整考试。

5. **本周零成本启动**：AWS Skill Builder「Introduction to AWS Cloud」10 个免费实验室 + Microsoft Learn SC-500/AB-410 免费路径，两条线都不需要花钱，这周把其中一条学习计划开起来，比规划多、行动少更有用。
