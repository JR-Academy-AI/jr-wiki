## 一、认证动态

### 1. AZ-500 下月 31 日退役，SC-500「Cloud and AI Security Engineer」全面接班

**一句话**：还没拿到 AZ-500 的人只有36天，过了8月31日这张考卷永远消失。

AZ-500（Microsoft Certified: Azure Security Engineer Associate）将于 **2026年8月31日正式退役**，接棒者是 **SC-500：Implementing End-to-End Security Controls for Cloud and AI Workloads**，认证头衔更名为 **Microsoft Certified: Cloud and AI Security Engineer Associate**。

不只是改名，考域结构也变了：

- **考试时长**：120 分钟
- **通过线**：700 / 1000 分
- **新增考域**：AI 工作负载安全（AI Workload Security）——这在 AZ-500 里完全不存在
- **Beta 开放**：5月15日已可报考 beta 场次；beta 考试价格通常比正式场便宜约 25%

目前 SC-500 仍处于 beta 阶段。Beta 成绩不实时出分，通常需要 4–8 周，但通过即获正式认证，不用再考。

两个务实建议：（1）如果你已在准备 AZ-500，这36天内考完；（2）如果还没开始，直接跳 SC-500 beta，早考早拿，而且成本更低。

> 来源：[AZ-500 Is Retiring August 31, 2026 — Your SC-500 Transition Guide](https://dailydebian.com/blogs/it-certification-news/az-500-is-retiring-on-august-31-2026-heres-your-sc-500-transition-plan) · [Microsoft Certification Retirements 2026](https://www.aicloudpartners.com/guides/microsoft-certification-retirements-2026.html)

### 2. Kubernetes CARE 扩展：通过 CKS 考试可自动延续或恢复 CKA

**一句话**：考一张 CKS，顺手续了 CKA——不用再花时间重考 Kubernetes 基础。

Linux Foundation 和 CNCF 于 **2026年6月18日** 宣布 CARE（Certification Associate Recertification Extension）计划的新扩展：**通过或重考 CKS（Certified Kubernetes Security Specialist），可自动更新 CKA（Certified Kubernetes Administrator）的到期日**。

具体规则：
- CKA **有效期内**：通过 CKS，CKA 到期日同步更新为 CKS 到期日
- CKA **已过期**：通过 CKS 可直接**恢复**已失效的 CKA，到期日定为 CKS 的到期日
- 反向不成立：CKA 不能延续 CKS

CKS 考试定价 $375，2 小时，全程命令行操作，有效期 3 年。对于已有 CKA 的 DevOps / SRE / 平台工程师来说，花一次考试费相当于同时解决两张证的续期问题。

> 来源：[Expanding CARE: Passing CKS can now extend your CKA certification — CNCF Blog](https://www.cncf.io/blog/2026/06/17/expanding-care-passing-cks-can-now-extend-your-cka-certification/) · [Linux Foundation Blog](https://training.linuxfoundation.org/blog/expanding-care-passing-cks-can-now-extend-your-cka-certification/)

### 3. AWS Lab Maker：自然语言描述，AI 秒出 hands-on 实验步骤

**一句话**：告诉 Lab Maker 你想练什么，它给你生成一套步骤、直接叠在模拟 AWS Console 上。

AWS Training and Certification 在 **2026年5月**正式发布 **Lab Maker**，一个内嵌在 AWS Skill Builder 的 AI-powered 实验生成工具。操作模式：用自然语言描述你想构建的场景（比如"给我一个 Lambda + API Gateway + DynamoDB 的 CRUD demo"），Lab Maker 实时生成分步骤引导，叠加在 AWS Management Console 模拟界面上。

适用场景：
- 刚学完某个服务理论，想立刻动手验证
- 备考 SAA / SAP / DevOps Pro 时针对薄弱考点练手
- 团队统一演练某个架构模式

当前仅对 **AWS Skill Builder Team 订阅用户**开放，个人订阅暂不包含。Lab Maker 也支持所有主流 AI 相关的 AWS 服务，如 Amazon Bedrock、Amazon Q 的实践场景。

> 来源：[Generate instant, personalized labs for popular AWS services — AWS Training Blog](https://aws.amazon.com/blogs/training-and-certification/labmakeraipoweredinstantpersonalizedhands-onlabs/) · [AWS May 2026 New Offerings](https://aws.amazon.com/blogs/training-and-certification/may-2026-new-offerings/)

### 4. GCP Professional ML Engineer 考纲大改：Vertex AI 更名 Gemini Enterprise Agent Platform，考题随之转向

**一句话**：Google Cloud Next 2026 把 Vertex AI 改名为 Gemini Enterprise Agent Platform，PMLE 考纲跟着更新，考 agent-building 和 RAG pipeline 的权重大幅上升。

Professional Machine Learning Engineer（PMLE）是 GCP 技术含量最高的认证之一。Google Cloud Next 2026 发布了一个重要平台更名：**Vertex AI 改名为 Gemini Enterprise Agent Platform**，随之 PMLE 的考纲内容也在做相应修订：

- 减少传统 AutoML 和模型训练流程题
- 增加 **Agent 构建**（Gemini API agent design）
- 增加 **RAG pipeline 设计与优化**（Retrieval-Augmented Generation）
- MLOps 部分转向 Gemini 平台上的持续监控与再训练

目前备考 PMLE 的人注意：旧版备考资料（2024 年以前）覆盖的 Vertex AI SDK 和 AutoML 操作路径可能与最新考题出现偏差，建议优先参考 Google Cloud 官方最新 exam guide。

> 来源：[Google Cloud Certification Exam Updates — TestPrepTraining](https://www.testpreptraining.ai/blog/google-cloud-certification-exam-updates/) · [Google Cloud Certification Changes 2026](https://www.3university.io/learn/google-cloud-certification-changes/)

## 三、JR Academy 学员行动建议

1. **AZ-500 持有者或在考者：** 8月31日是死线——退役后不再接受新考。已经复习过半的同学本周就去约考，SC-500 beta 仍可报，但官方成绩出分需要等 4–8 周，不如直接在 8月底前锁定 AZ-500。

2. **已拿 CKA 的 DevOps / SRE 同学：** CKS 是你下一张该考的证。$375 一次，把 CKA 顺带续了，加 Kubernetes 安全能力到简历上，一箭双雕。JR Academy Kubernetes 进阶课程对应了完整的 CKS 考域，可在课程中台查看学习路径。

3. **在读学生：** 立刻去 [aws.amazon.com/about-aws/our-impact/scholars/](https://aws.amazon.com/about-aws/our-impact/scholars/) 申请 AWS AI & ML Scholars，免费拿到 Skill Builder 订阅和 Lab Maker 权限，备考成本直接归零。

4. **想补 AI 安全知识的 Azure 路线学员：** SC-500 新考域中 AI Workload Security 部分是 AZ-500 从未涉及的。现在先完成 Microsoft Learn 的 AI Challenge，拿 50% 折扣券，再报 SC-500 beta，既节省考费，又提前适应新题型。

5. **GCP PMLE 备考中：** 旧的 Vertex AI SDK 教程已不完全对应最新考纲。切换到 Google Cloud 官网的最新 [PMLE exam guide](https://cloud.google.com/learn/certification/machine-learning-engineer)，Gemini Enterprise Agent Platform 章节是新增重点，先把官方 Agentic AI 免费路径刷一遍再做题。
