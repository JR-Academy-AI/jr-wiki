## 一、认证动态

### 1. Anthropic Claude 认证：Global Premier 合作伙伴 8 月 31 日免费截止

**一句话**：如果你所在的公司是 Claude Partner Network Global Premier 成员，8 月 31 日前参加所有 Claude 认证考试费用 100% 由 Anthropic 覆盖——最贵的 Architect Professional 也是零元。

Anthropic 今年 3 月随 Claude Partner Network 正式推出认证体系，现开放四张证书：

| 考试名称 | 标准价格 |
|---|---|
| Claude Certified Associate, Foundations | USD $99 |
| Claude Certified Developer, Foundations | USD $125 |
| Claude Certified Architect, Foundations | USD $125 |
| Claude Certified Architect, Professional | USD $175 |

所有考试统一格式：时长 120 分钟，满分 1,000 分，720 分及格，通过 Pearson VUE 线上监考或考场作答，证书有效期 12 个月（到期可免费续约一次）。

**8 月 31 日到期的优惠细节**：Global Premier 合作伙伴成员在这个日期前报考全部免费；Select 和 Preferred 级别合作伙伴享受常规 5 折。9 月起恢复标准全价，全考一遍最多需要 USD $524。

**关键限制**：这套认证**不向社会开放**。报名时要求考生的工作邮箱必须属于 Claude Partner Network 内已注册的组织。独立开发者、自由职业者、或非合作伙伴公司的员工目前无法报考。截至 7 月底，项目已培育超过 36,000 名持证顾问，覆盖 1,300 家以上组织。

如果你在 AI 咨询公司或者正在用 Claude API 的企业工作，现在就去问一下公司的 Partner Network 级别。17 天内搞清楚这一件事，可能省下 USD $524。

> 来源：[Claude Certification 2026: All 4 Anthropic Exams — felloai.com](https://felloai.com/claude-certification/)

### 2. ANS-C01 停考倒计时 11 天：8 月 25 日是最后机会

**一句话**：AWS Advanced Networking Specialty 考试（ANS-C01）2026 年 8 月 25 日是最后一天可以参加，没有替代考试，没有 ANS-C02，过期无法补考。

今天（8 月 14 日）距截止日还有 11 天。这张证书涵盖 AWS 网络架构、混合云连接、Transit Gateway、Direct Connect、Route 53 等深度考点，是网络方向工程师常规的晋升证书之一。

考前要确认的几件事：
- 已购买 AWS 认证考试凭证但还没预约时间的，**立刻进 Pearson VUE 把时间锁定**，8 月 25 日前完成考试
- 已过的证书在标准 3 年有效期内继续有效，不受停考影响
- AWS 官方暂无宣布继任考试路径，网络专项方向在 ANS-C01 退场后目前是空白

如果你的认证计划里有这张证书，今天就去报名，不要等到最后两天。

> 来源：[AWS Advanced Networking Specialty Retires 25 August 2026 — certcrush.app](https://www.certcrush.app/blog/aws-advanced-networking-specialty-retiring-2026)

### 3. Microsoft Azure Analytics 专项合并：三合一变统一路径

**一句话**：8 月初，微软将原本三个独立的 Azure 分析类合作伙伴专项合并为单一的「Analytics on Microsoft Azure」专项，简化认证路径。

三个被合并的专项：Analytics on Microsoft Azure、Data Warehouse Migration to Microsoft Azure、Business Intelligence。合并后统一使用「Analytics on Microsoft Azure」名称，对应的能力要求重新梳理整合。

这次调整主要影响**微软合作伙伴公司**的专项资质认定，不涉及 DP-900、DP-203 等面向个人的考试代码。如果你所在的公司在维护或争取微软分析方向的合作伙伴专项，这个路径调整值得跟进——旧专项资质在过渡期后将统一迁移到新路径。

对个人考生直接影响有限，但如果 DP-203（Azure Data Engineer Associate）在你的学习计划里，认证路径现在比之前更清晰了。

> 来源：[Microsoft Credentials roundup: June 2026 — Microsoft Community Hub](https://techcommunity.microsoft.com/blog/skills-hub-blog/microsoft-credentials-roundup-june-2026/4528350)

## 二、免费 / 限免课程

### 1. Google Cloud Arcade Base Camp August 2026（本月限时，完课送积分兑奖品）

**适合**：想刷 Google Cloud 实操经验、备考 GCP 认证、或给简历加一条「有动手 lab 经历」的学员
**链接**：[Arcade Base Camp August 2026](https://www.skills.google/games/7394)

Google Cloud Arcade 是 Google Cloud 每月一届的免费闯关活动：在真实 GCP 环境里完成 lab、技能挑战和游戏题，积累积分后可兑换实物（T 恤、贴纸、Google Cloud 周边）。8 月的 Base Camp 专门为新加入 Google Cloud Skills Boost 平台的学员设计，完成后颁发独立的入门凭证徽章。

积分规则：每完成一个 game badge 或 trivia badge = 1 积分；每完成 2 个 skill badge = 1 积分（每个 skill badge 0.5 积分）。

怎么开始：

1. 在 [cloudskillsboost.google](https://cloudskillsboost.google) 注册（免费账号即可）
2. 进入 [Arcade Base Camp August 2026](https://www.skills.google/games/7394)
3. 按页面指引完成 lab

Google Cloud Skills Boost 平台上目前 300 多门课程提供免费完成徽章，其中 GenAI 入门系列（Generative AI、Responsible AI、LLMs、Image Generation、Transformer Models 共五门）每门不超过 45 分钟，全部在免费层可直接访问。

### 2. AWS Skill Builder「Building Language Models on AWS」（免费，完课颁官方证书）

**适合**：有 Python/ML 基础的数据科学家和工程师，想深入了解 LLM 在 AWS 平台上的完整建模和部署流程
**链接**：[Building Language Models on AWS — Skill Builder](https://skillbuilder.aws/learn/MRAJEZFMW7/building-language-models-on-aws/HC76V3KSK4)

这门课由 AWS 直接出品，内容覆盖大语言模型开发全链路：

- 大型文本语料的存储与预处理策略
- 分布式训练挑战与性能优化
- Amazon SageMaker Jumpstart 上的基础模型部署
- 生成式 AI 任务的微调方法

课程包含文字讲义、图解和视频演示，视频里演示的 lab 操作可在自己的 AWS 账号里复现。完成后 AWS 官方颁发完成证书，**全程免费**。

定位说明：这不是「认识云」的入门课。目标学员是已经在用 SageMaker 但面对大模型训练时发现存储、调度和微调有盲区的工程师——如果你能看懂 SageMaker Pipelines 但从没训练过亿级参数的模型，这门课正好填这个坑。

## 三、JR Academy 学员行动建议

**① 今天就去核查你公司的 Claude Partner Network 级别**

如果公司是 Global Premier，8 月 31 日前四张 Claude 认证 100% 免费，总价 USD $524 的考试费全免。问 BD、问 HR、问 CTO，把这件事在本周内弄清楚。Associate Foundations（$99，最短备考路径）一个周末可以搞定，先过一张再说。

**② 还没考 ANS-C01 的，今天就去报名**

11 天后永久停考，不补考，不退款。如果这张证书在你的职业规划里，现在就进 [Pearson VUE](https://www.pearsonvue.com/us/en/amazon-web-services.html) 锁定 8 月 25 日之前的时间段。备考材料还来得及刷完一遍重点章节。

**③ 把 AWS LLM 建模课拿进本周计划**

这是 AWS 官方免费课程，完课有证书，内容直接对应大厂数据科学岗「有 LLM 部署经验」的要求。JR Academy 数据科学方向的同学把这张完成证书加进简历「在线学习」一栏，比空着要好。链接：[skillbuilder.aws](https://skillbuilder.aws/learn/MRAJEZFMW7/building-language-models-on-aws/HC76V3KSK4)

**④ 这个月用 Google Cloud Arcade 刷 1-2 个免费 badge**

不花钱，不需要特别 GCP 经验，完成 Base Camp 就有徽章和积分。面试时「在 Google Cloud 真实环境做过 lab」比「看完了官方文档」多了一层可信度。8 月限时，进 [Arcade Base Camp](https://www.skills.google/games/7394) 报名。

**⑤ 考虑订 Coursera Plus 的，本月是近期折扣价**

三个月 $35.40/月 包含全部专业证书访问权限。如果接下来三个月计划系统备考 Google Data Analytics 或 Microsoft Azure 系列，单独按课程购买证书比订 Coursera Plus 贵。算一下再决定。
