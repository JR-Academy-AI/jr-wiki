### 2. AZ-204 今夜 CST 最终关停：接班者 AI-200 已上线，同价 $165

**一句话**：AZ-204（Azure Developer Associate）将于北美中部时间 7月31日 11:59 PM（北京时间 8月1日下午 2:59，AEST 8月1日下午 3:59）永久关闸；还没报过 AZ-204 的直接上 AI-200，同价格、考域更新。

AZ-204（Developing Solutions for Microsoft Azure）退役进入最后时间窗：考试入口将于**北美中部时间 2026 年 7 月 31 日 11:59 PM** 永久关闭。已持 AZ-204 证书者不受影响，但认证到期后续期路径也随之消失。

接班者是 **AI-200（Developing AI Cloud Solutions on Azure）**，对应认证名称 **Azure AI Cloud Developer Associate**，2026 年 7 月已正式 GA（Beta 从 4 月开放）。核心考域从通用 App Service / 函数计算切换至 Azure OpenAI 集成、语义搜索、RAG、向量数据库、容器化 AI 工作负载，考试价格维持 **$165 USD** 不变。

**AZ-204 vs AI-200 对比：**

| 项目 | AZ-204 | AI-200 |
|------|--------|--------|
| 认证名称 | Azure Developer Associate | Azure AI Cloud Developer Associate |
| 价格 | $165 USD | $165 USD |

| 核心方向 | App Service、存储、CosmosDB、函数 | Azure OpenAI、AI Studio、RAG、向量 DB |

现在才开始备考的直接选 AI-200——同价格、更新的方向、市场需求更旺。AI-200 官方学习路径在 Microsoft Learn 免费开放，搭配 Azure 免费账户可完成全部动手实验。

### 3. Google Cloud Next '26：Gemini Enterprise Agent Platform + TPU 8t/8i 重塑 GCP 技能图谱

**一句话**：Google Cloud Next '26 正式发布 Gemini Enterprise Agent Platform（低代码 Agent 构建 + 全组织 Agent 注册中心 + Agent 间编排），TPU 8t 算力是上代 Ironwood 3 倍——对 GCP 认证学员来说，Agent 架构师方向从"未来考点"变成"现在要补的内容"。

Google Cloud Next '26 最影响认证方向的两大发布：

**Gemini Enterprise Agent Platform（全新平台）：**

- **Agent Studio**："Our new low-code interface, enables every developer to build, test, and publish agents using natural language"——低代码构建 Agent，无需深度 ML 背景
- **Agent Registry**："Provides a single point of control, indexing every internal agent and tool across your organization"——单点管控全组织 Agent
- **Agent-to-Agent Orchestration**：Agent 之间可互相委托任务，支持长时 Agent 流程

**AI 基础设施新一代（TPU 8 系列）：**

- **TPU 8t**（训练）："Achieves 3x the processing power of Ironwood and delivers up to 2x more performance/Watt"
- **TPU 8i**（推理）："Delivers 80% better performance per dollar for inference than the prior generation"
- **Managed Lustre** 存储：达到 10 TB/s 吞吐

**其他值得关注：**

- Claude Opus 4.7 已在 Google Cloud 上线，可直接调用
- **Cross-Cloud Lakehouse**（基于 Apache Iceberg）：零复制跨 AWS / Azure 访问数据，无供应商锁定
- "Nearly 75% of Google Cloud customers are using our AI products to power their businesses"

**对 GCP 认证学员的意义**：Professional Cloud Architect、ML Engineer、Data Engineer 三张证书的考域正在向 Agent 架构和 Vertex AI 扩展。建议持证人现在就去 Cloud Skills Boost 刷 Gemini Agent 相关徽章——这些徽章很可能是 2026 年续期评估的新选项之一。

> 来源：[Google Cloud Blog — Welcome to Google Cloud Next '26](https://cloud.google.com/blog/topics/google-cloud-next/welcome-to-google-cloud-next26)（官方原文，已验证）

### 4. Databricks 7 月更新：Lakeflow Connect 行过滤 GA，Gemini 图像模型上线

**一句话**：Databricks 7 月把 Lakeflow Connect 行过滤推进 GA，摄入时就能用 SQL WHERE 条件过滤数据；Gemini 3.1 Flash Image 和 Gemini 3 Pro Image 现在可作为 Databricks 托管模型直接调用。

两条具体更新来自 Databricks 官方 7 月 Release Notes：

1. **Lakeflow Connect 行过滤正式 GA**：可在摄入时用类 SQL WHERE 条件只拉取需要的行，支持 SaaS 连接器包括 Google Analytics、Salesforce、ServiceNow，以及所有基于查询的连接器。备考 Databricks Certified Data Engineer 的学员需关注此新增 Lakeflow 功能。

2. **Gemini 图像模型 Databricks 托管上线**：Model Serving 现支持 **Gemini 3.1 Flash Image** 和 **Gemini 3 Pro Image** 作为 Databricks 托管模型，无需自行部署和配置。

> 来源：[Databricks Release Notes — July 2026 (AWS)](https://docs.databricks.com/aws/en/release-notes/product/2026/july) / [Databricks Release Notes — July 2026 (GCP)](https://docs.databricks.com/gcp/en/release-notes/product/2026/july)
