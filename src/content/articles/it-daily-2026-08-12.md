## 一、认证动态

### 1. AZ-802 本月正式 GA：一证整合 Windows Server，AZ-800/AZ-801 九月底出局

**一句话**：微软把两张 Windows Server 考试压成一张，AZ-802 八月上线，旧证九月三十日 17:00 CT 停考。

微软在七月启动了 AZ-802 Beta，本月进入正式 GA（General Availability）阶段。考试全名为 **Exam AZ-802: Administering Windows Server**，对应认证升级为 **Microsoft Certified: Windows Server Administrator Associate**。

和旧路径的区别一目了然：AZ-800（Administering Windows Server Hybrid Core Infrastructure）+ AZ-801（Configuring Windows Server Hybrid Advanced Services）合二为一，考一次就拿证。覆盖范围不变，涵盖混合基础架构管理、存储、身份、混合网络与 Azure 集成，新考试重点强化了 Azure Arc 管理 Windows Server 的部分。

**时间节点**：AZ-800 / AZ-801 在 **2026 年 9 月 30 日（美东时间下午 5 点）** 停考。停考后已持有的认证仍然有效至原到期日，但想获新认证只能走 AZ-802。目前在考的人如果两科都还没过，直接转 AZ-802 备考效率更高。

> 来源：[tutorialsdojo.com – AZ-802 Study Guide](https://tutorialsdojo.com/az-802-windows-server-hybrid-administrator-study-guide/)  
> 参考：[Microsoft Community Hub – New Exam AZ-802](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-exam-for-microsoft-certified-windows-server-administrator-associate-certific/4494120)

### 2. Security+ SY0-801 定档十一月：首次加入 LLM 与 AI 威胁考点

**一句话**：CompTIA 确认 Security+ 801 将在 2026 年 11 月 17 日正式发布，SY0-701 持续有效到 2027 年中旬，不用急着抢考或死等。

SY0-801 的最大变化不在总体框架，而在两个新目标：

- **Objective 2.4**：Large Language Models——考验候选人理解 LLM 安全风险（提示注入、数据投毒、模型窃取）的能力
- **Objective 2.6**：AI Usage in Threats and Vulnerabilities——覆盖 AI 辅助攻击手法（深度伪造钓鱼、AI 生成恶意代码检测）

这不是一次版本替换，而是在现有 SY0-701 结构上做内容刷新，考试代码更新为 801，但整体出题逻辑与 701 兼容。

**时间线**：
- 预览版（Preview Access）：2026 年 10 月 20 日
- 正式 GA：2026 年 11 月 17 日
- SY0-701 预计退场：2027 年中旬（按 CompTIA 惯例，新版上线 6 个月后旧版退场）

**现在该怎么办**：已经开始备考 701 的不要停——拿到 701 同样有效三年，而且 801 发布后 701 至少还能考半年。只有从零开始、打算 10 月后才启动备考的人才有必要直接等 801。

> 来源：[Security+ SY0-701 vs SY0-801: What Changes | Ryno Tools](https://ryno.tools/blog/sy0-701-vs-sy0-801-security-plus/)  
> 参考：[Security+ 801 Is Coming, Don't Stall | Medium](https://medium.com/@bogdogcert/security-801-is-coming-dont-let-that-stall-you-9ba1a4caa6e3)

### 3. AB-250 Dynamics 365 Contact Center AI Engineer：Beta 冲刺，AI 联络中心新方向

**一句话**：微软推出全新 AI 方向认证 AB-250，聚焦 Dynamics 365 联络中心 + Copilot + 自主 Agent 场景，适合做 CCaaS 方案的工程师。

**Exam AB-250: Transforming Contact Center Experiences with AI in Dynamics 365** 目前处于 Beta 阶段，正式版上线时间预计随时跟进。Beta 早鸟折扣（8 折，前 300 人，截止 6 月 18 日）已过，正式版标准价参照微软认证惯例约 $165 USD。

考试验证的核心技能：

- **Channel Implementation（30–35%权重，最重）**：语音、数字渠道配置
- **Agent and AI Configuration**：Copilot Studio 自主 Agent 搭建与调优
- **Work Distribution Configuration**：技能路由、队列管理
- **Analytics and Supervisor Management**：实时分析与质检

适合人群：有 6–12 个月 Dynamics 365 Contact Center + Power Platform 实战经验的方案工程师或顾问。纯 CRM 背景不够，需要有一定 Copilot Studio / AI Builder 动手经验。

> 来源：[Microsoft Community Hub – AB-250 Certification](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-dynamics-365-contact-center-ai-engineer-associate-certif/4494119)

### 4. GCP 认证延期窗口：8 月 31 日前完成 Skill Badge 可再延 12 个月

**一句话**：PCA / PDE / ACE / CDL 四张 GCP 认证如果 2026 年内到期，完成指定 Skill Badge 可免费续期一年——截止今天还有 19 天窗口。

Google Cloud 给了一次性续期政策：PCA（Professional Cloud Architect）、PDE（Professional Data Engineer）、ACE（Associate Cloud Engineer）、CDL（Cloud Digital Leader）认证若在 2026 年 1 月 1 日至 8 月 31 日之间到期或失效，可以通过在 Google Skills 完成指定技能徽章来获得 **12 个月的延期**，完成截止日期同为 **2026 年 8 月 31 日**。

具体要求的 Skill Badge 因认证而异，在 Google 官方支持页面可查到对应列表。这比重考省时间省钱（GCP 专业级考试单次 USD $200），值得在 8 月底前抢着做完。

> 来源：[Google Cloud Certification Renewal | support.google.com](https://support.google.com/cloud-certification/answer/9907853?hl=en)

## 二、免费 / 限免课程

### 1. Google GEAR：4 条 Agentic AI 学习路径，每月 35 学分，免费

**适合**：想系统学 AI Agent 开发的云工程师、AI 工程师，有 Python 基础即可  
**链接**：[https://www.skills.google/paths/](https://www.skills.google/paths/)

Google 在 Cloud Next '26 发布的 GEAR（Google Enterprise AI Readiness）计划，核心是每月 **35 个免费学习学分**，用于在 Google Skills 平台解锁课程和 Hands-on Lab。四条 Agentic AI 学习路径全部包含在内：

1. **Introduction to Agents and Google's Agent Ecosystem**（入门）
2. **Develop Agents with Agent Development Kit（ADK）**（动手开发）
3. **Deploy Production-Ready Agents**（生产部署）
4. **Scale Agents Across the Enterprise**（企业规模化）

这四条路径形成完整的 Agent 开发闭环，从概念到 ADK 框架到生产部署，无需额外付费。对已有 Google Cloud 账户的用户，还可同步参与 **Get Certified** 项目，使用额外学分备考 GCP 认证，同样零成本。

> 来源：[Google Cloud Blog – GEAR at Cloud Next '26](https://cloud.google.com/blog/topics/training-certifications/gear-up-to-get-the-most-out-of-ai-learning-at-google-cloud-next26)

## 三、JR Academy 学员行动建议

1. **考 Windows Server 的同学**：如果你还在两科之间犹豫，直接转 AZ-802 备考——九月底 AZ-800/AZ-801 停考，届时所有 prep material 都会集中转向 AZ-802，早动手早上岸。

2. **备考 Security+ 的同学**：不要因为 SY0-801 即将上线而停下来等。SY0-701 至少到 2027 年中才退场，现在拿到 701 就已经值三年。只有打算 10 月之后才开始备考的人才考虑直接等 801。

3. **GCP 认证已到期或快到期**：今天（8 月 12 日）起只剩 19 天，登录 Google Skills 核查你的认证状态，完成对应 Skill Badge 即可免费延期 12 个月，比重考便宜 $200。

4. **想系统学 Agent 开发**：Google GEAR 的 4 条路径和 Hugging Face Agents Course 配合吃——GEAR 侧重 GCP 生态（ADK + Vertex AI），HF 侧重 smolagents/LangGraph，两套框架都摸一遍，面试时选题空间大得多。

5. **有 Dynamics 365 背景的同学**：关注 AB-250 GA 时间，提前读官方考试目标（Exam Skills Outline 在 Microsoft Learn 可下载），Channel Implementation 权重最高（30–35%），重点放那里。
