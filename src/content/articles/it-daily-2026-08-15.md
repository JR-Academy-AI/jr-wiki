## 一、认证动态

### 1. SC-500 正式接棒 AZ-500，倒计时 16 天

**一句话**：Microsoft 全新的 SC-500（Cloud and AI Security Engineer Associate）七月已正式 GA，AZ-500 将于**八月三十一日**终止——持有 AZ-500 的学员现在必须决定是否转考 SC-500。

AZ-500 陪伴了 Azure 安全工程师七年，但它的考试范围始终没有涵盖 AI 安全。SC-500 在原有安全域基础上新增了一整块 AI 安全板块：Copilot、Entra Agent ID、Azure AI Foundry 相关的身份与访问控制，正好对应现在大量企业部署 Copilot for Microsoft 365 的真实需求。

**SC-500 考试信息（官方来源：Microsoft Community Hub 和 skillcertpro.com）**：

| 项目 | 详情 |
|---|---|
| 考试代码 | SC-500 |
| 正式名称 | Microsoft Certified: Cloud and AI Security Engineer Associate |
| 考试价格 | USD $165 |
| 考试时长 | 100 分钟 |
| 通过分数 | 700 / 1000 |
| 题目数量 | 约 40–60 题 |
| AZ-500 停考日期 | **2026 年 8 月 31 日** |

**四大考试域**：
- 身份 / 存储 / 网络安全（沿用 AZ-500 核心域）
- Defender for Cloud + Microsoft Sentinel（云 SIEM / SOAR）
- **AI 安全新域**：Copilot 访问控制、Entra Agent ID、Azure AI Foundry 模型安全
- 合规与治理

已持有 AZ-500 的学员：证书有效期不受停考影响，到期后可直接报 SC-500 续期。没拿 AZ-500 的学员：直接冲 SC-500，不要再花时间备考一张本月就停的证。

> 来源：[Microsoft Community Hub — New Microsoft Certified: Cloud and AI Security Engineer Associate](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-cloud-and-ai-security-engineer-associate-certification/4494117)、[SC-500 Certification: AZ-500 Retirement & Which to Take](https://www.certcrush.app/blog/az-500-vs-sc-500-which-microsoft-security-cert-2026)

### 2. AZ-802 本月 GA：一张考试接管 AZ-800 + AZ-801

**一句话**：Microsoft 把 Windows Server 的两张考试（AZ-800 和 AZ-801）合并成一张 AZ-802，本月正式 GA，原来两张考试九月三十日停考。

之前备考 Windows Server Hybrid Administrator 需要通过 AZ-800 和 AZ-801 两张，各 $165，共 $330。AZ-802 合并后，**一张考试拿同一张证书**，考试费用减半。这对在读备考 AZ-800 / AZ-801 的学员影响很大：如果还没考完两张，建议本月切换到 AZ-802 复习路径。

**AZ-802 考试信息（官方来源：Microsoft Community Hub、azurefeeds.com）**：

| 项目 | 详情 |
|---|---|
| 考试代码 | AZ-802 |
| 正式名称 | Microsoft Certified: Windows Server Administrator Associate |
| 通过分数 | 700 / 1000 |
| AZ-802 Beta | 2026 年 7 月（已开放） |
| AZ-802 正式 GA | 2026 年 8 月 |
| AZ-800 / AZ-801 停考 | **2026 年 9 月 30 日 17:00 Central** |

**主要覆盖域**：
- 部署与管理 Active Directory Domain Services（AD DS）
- Windows Server 实例与工作负载混合管理（Azure + 本地）
- 网络与存储基础设施
- 高可用性与灾难恢复

> 来源：[New exam for Microsoft Certified: Windows Server Administrator Associate — Microsoft Community Hub](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-exam-for-microsoft-certified-windows-server-administrator-associate-certific/4494120)、[Azure Feeds 报道](https://azurefeeds.com/2026/07/09/new-exam-for-microsoft-certified-windows-server-administrator-associate-certification/)

### 3. AWS MLA-C02 Beta 九月一日开报，MLA-C01 九月二十八日停考

**一句话**：AWS 将更新 Machine Learning Engineer – Associate 认证：新版 MLA-C02 Beta 九月一日开放报名（$75，85 题，170 分钟），当前 MLA-C01 英文版九月二十八日停考。

这次更新是 AWS 认证追赶 GenAI 时代的关键动作。MLA-C01 发布于 2024 年底，当时生成式 AI 在工程侧还是新生事物；两年过去，企业 ML 工程师日常工作已经深度涉及 Bedrock、RAG、Agent workflow——原版考试覆盖不到，MLA-C02 全面补上。

**MLA-C02 Beta 信息（来源：AWS Training and Certification Blog）**：

| 项目 | 详情 |
|---|---|
| 新版考试代码 | MLA-C02 |
| Beta 开报日期 | **2026 年 9 月 1 日**（英文版，Pearson VUE） |
| Beta 考试时长 | 170 分钟 |
| Beta 题目数量 | 85 题 |
| Beta 价格 | **USD $75**（标准版约 $150–165） |
| MLA-C01 英文停考 | **2026 年 9 月 28 日** |
| MLA-C01 其他语言 | 日韩中文 Beta 期间继续可考 |

**MLA-C02 新增考试内容**：
- 生成式 AI 实现（Fine-tuning、RAG 架构）
- Amazon Bedrock 与 Foundation Model 工作负载
- AI Agent 工作流设计与编排
- 负责任 AI 与模型安全（展开覆盖）

正在备考 MLA-C01 的学员：**九月二十八日前用英文版冲关，或等 Beta 用 $75 考新版**——两条路都行，但别拖到十月什么都没有。

> 来源：[Updates to AWS Certified Machine Learning Engineer – Associate (MLA-C02) | AWS Blog](https://aws.amazon.com/blogs/training-and-certification/updates-to-aws-certified-machine-learning-engineer-associate-mla-c02/)

### 4. Azure 数据分析三项合作伙伴专项本月合并

**一句话**：从 2026 年 8 月起，微软把三个独立的 Analytics 合作伙伴专项（Analytics on Microsoft Azure、Data Warehouse Migration to Microsoft Azure、Business Intelligence）合并为统一的「Analytics on Microsoft Azure」专项，现有合作伙伴自动划入新专项。

这对在微软合作伙伴体系里做数据 / BI 业务的公司有直接影响——**原来三条路径的能力要求合一**，Partners 不需要重新申请。对个人学员的影响相对间接：进入合作伙伴公司后，公司整体走哪个专项会影响你的证书组合规划。

> 来源：[June 2026 announcements — Microsoft Partner Center](https://learn.microsoft.com/en-us/partner-center/announcements/2026-june)

## 三、JR Academy 学员行动建议

1. **AZ-500 持有者（或正在学 AZ-500）**：不要再花时间备 AZ-500 了。八月三十一日前考完可以，但不如直接切换到 SC-500 资料——新版覆盖内容与旧版大部分重叠，多学的 AI Security 域正好是当前就业市场缺口。

2. **在读 AZ-800 / AZ-801 的学员**：本月 AZ-802 正式 GA 后，去 Microsoft Learn 下载 AZ-802 考试大纲对比你现有的学习进度。如果两门都还没考，转考一门 AZ-802 省 $165，九月三十日之前有充足时间。

3. **AWS ML 方向学员（备考 MLA-C01）**：中文和日韩版 MLA-C01 Beta 期间继续可考，可以先把英文版备考材料清完；如果七月才开始备考 MLA-C01 英文版，也可以等九月一日花 $75 参加 MLA-C02 Beta——新版有官方答题指南。

4. **刚入门云的学员**：本周把 Google Cloud Skills Boost 的 Innovators 账号注册好，35 积分上「Intro to GenAI」+ 「Prompt Design in Vertex AI」，两课 90 分钟拿两枚数字徽章。同步跑 AWS Skill Builder 的 Cloud Practitioner Essentials，两条线齐上，月底做一次选方向的决定再深入。

5. **想做 AI Agent 开发的学员**：Hugging Face Agents Course 的 Unit 1–2（smolagents + LangGraph）是当前最贴近生产环境的免费 Agent 教程，完成后直接去 [JR Academy AI 工程课程](https://jiangren.com.au/course) 看进阶路径。
