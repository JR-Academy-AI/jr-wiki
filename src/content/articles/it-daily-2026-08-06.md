## 一、认证动态

### 1. AZ-802 正式版本月上线：两门 Windows Server 考试合并，AZ-800 / AZ-801 将于 9 月底退场

**一句话**：微软将 AZ-800 和 AZ-801 合并成一门 AZ-802，正式版本月（2026 年 8 月）推出，持有旧认证的人暂不受影响，但备考 AZ-800 / AZ-801 的人要调头。

AZ-802（Microsoft Certified: Windows Server Administrator Associate）把原来两门分开的考试打包成一个凭证：AZ-800（Administering Windows Server Hybrid Core Infrastructure）负责基础层，AZ-801（Configuring Windows Server Hybrid Advanced Services）负责进阶层，现在两门功能合一，统一走 AZ-802。

**关键时间线**：
- Beta 考试：2026 年 7 月已开放报名
- 正式版：2026 年 8 月上线（即本月）
- AZ-800 / AZ-801 退场日：**2026 年 9 月 30 日**
- 通过分数：700 分（满分 1000 分）

对已拿到 Windows Server Hybrid Administrator 认证的人：证书本身不受影响，不需要重考。对正在备考 AZ-800 或 AZ-801 的人：如果短期内能考完，在 9 月 30 日前考原题仍然有效；如果还没开始，直接备考 AZ-802 更划算，避免用两套考纲买时间。

AZ-802 考核重点涵盖 Windows Server 管理、混合网络、存储、身份管理以及 Azure 集成，整体架构与旧两门的并集相同，但以单一蓝图呈现，复习路径更清晰。

> 来源：[New exam for Microsoft Certified: Windows Server Administrator Associate | Microsoft Community Hub](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-exam-for-microsoft-certified-windows-server-administrator-associate-certific/4494120)

### 2. AB-410 接替 PL-200：Power Platform 认证迁移路径，月底截止

**一句话**：PL-200（Power Platform Functional Consultant Associate）2026-08-31 正式退场，接班的是 AB-410（Intelligent Applications Builder Associate），聚焦 Copilot + 低代码 AI 应用。

PL-200 是 Power Platform 功能顾问方向的主力认证，现在微软把它替换成 AB-410，强化了 AI 驱动的方向。AB-410 的官方定位是：用 Power Platform 设计、构建并实施 AI 驱动解决方案，覆盖数据建模、Model-driven 应用、Canvas 应用、云端流、Copilot 集成，以及 AI 能力和业务逻辑。

**考试信息**：
- 考试代码：AB-410
- 认证名称：Microsoft Certified: Intelligent Applications Builder Associate
- 考试时长：120 分钟
- Beta 阶段：前 300 名考生（截止 2026-06-17）享 8 折优惠
- PL-200 退场日：**2026-08-31**（距今约 25 天）

如果你目前手上有 PL-200 认证，证书暂时有效，但微软通常在旧考退场后就不再推荐新职位用旧证做匹配。打算今年找 Power Platform 相关工作的学员，建议尽早切换到 AB-410 备考路径。AB-410 的官方学习路径在 Microsoft Learn 上已完整更新，免费可学。

> 来源：[Microsoft Certified: Intelligent Applications Builder Associate | Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/intelligent-applications-builder-associate/) / [Microsoft Tech Community Hub](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-intelligent-applications-builder-associate-certification/4494118)

### 4. Databricks Data Engineer Associate 考纲 5 月大改：旧材料可能已过期

**一句话**：2026-05-04 起，Databricks Data Engineer Associate 考纲从 5 章扩展到 7 章，新增 Lakeflow Jobs、CI/CD、故障排查三节，Delta Sharing 整段删掉；用去年或 2025 版材料备考的人要换资料。

Databricks 在 2026 年 5 月发布了新版官方考试指南（Exam Guide dated May 4, 2026），对 Data Engineer Associate 考纲做了较大幅度的结构性调整：

**新增内容（原考纲没有）**：
- Lakeflow Jobs（作业编排，替代旧版 Databricks Workflows 叫法）
- CI/CD 集成（Pipeline 持续集成部署）
- 故障排查与监控（Troubleshooting & Monitoring 独立成节）

**删除内容**：
- Delta Sharing（原来的数据共享模块整段移除）

**调整结构**：5 个领域 → 7 个领域，每节权重分布也有变化，需要以新版 Exam Guide 为准。

**考试固定参数**（未变）：
- 题数：45 道选择题
- 时长：90 分钟
- 费用：**$200 USD**
- 通过标准：官方未公布固定分数，社区普遍建议目标 80% 以上

如果你之前买了 Udemy 或第三方课程的 2025 版备考材料，先对照官网新版 Exam Guide 检查是否有对应章节。官方 PDF 在 databricks.com/learn/certification/data-engineer-associate 免费下载。

> 来源：[Databricks Certified Data Engineer Associate | databricks.com](https://www.databricks.com/learn/certification/data-engineer-associate) / [Databricks Certified Data Engineer Associate Exam Guide (May 4, 2026)](https://www.databricks.com/sites/default/files/2026-03/databricks-certified-data-engineer-associate-exam-guide-may-4-2026.pdf)

### 5. AWS AIP-C01 正式上线：$300 考生成 GenAI 开发专家，目前市场认可度最高的 AI 实操证

**一句话**：AWS Certified Generative AI Developer – Professional（AIP-C01）Beta 已于 2026-03-31 结束，标准版 3 月 17 日起开放报名，是目前三大云厂里对 GenAI 工程实践要求最具体的认证之一。

AIP-C01 的定位是验证候选人能否把基础模型（Foundation Models）集成进实际应用和业务流程，重点方向包括 RAG（检索增强生成）架构设计、向量数据库接入、Amazon Bedrock 实际部署，以及 AI 治理框架。这不是一张 AI 基础理论考，而是要求考生能写得出 pipeline、调得好 prompt、懂得选 model 和评估输出。

**考试参数**：
- 题数：65 道计分题 + 10 道不计分测试题（共 75 题）
- 通过分数：**750 / 1000**
- 考试费用：**$300 USD**
- 证书有效期：3 年
- 考试语言：英文为主，日文、韩文、简体中文等多语言可申请

对于 JR 的 AI 转行学员：如果已经拿了 AWS SAA-C03，AIP-C01 是目前跳板最短的 AI 工程师方向认证路径。Bedrock / RAG / 向量数据库这条技术线正好和 JR ML 工程课的覆盖面高度重叠，复习成本相对低。

> 来源：[All about the new AWS Generative AI Developer Professional exam | Pluralsight](https://www.pluralsight.com/resources/blog/cloud/new-aws-aip-c02-exam) / [AWS Training and Certification Blog](https://aws.amazon.com/blogs/training-and-certification/big-news-aws-expands-ai-certification-portfolio-and-updates-security-certification/)
