## 一、认证动态

### 1. Anthropic 成为首个推出完整 Pearson VUE 认证体系的前沿 AI 实验室

**一句话**：Anthropic 于 **2026 年 3 月 12 日** 正式推出 Claude 认证体系，现已扩展至 4 张证书，通过 Pearson VUE 第三方监考，定价 **$99–$175 USD**，但目前仅向 **Claude Partner Network** 成员组织开放。

这是 2026 年 IT 认证市场最意外的一个动向——不是 OpenAI，而是 Anthropic，率先成为首家完成正规化认证体系建设的前沿 AI 实验室。

**四张认证覆盖三个角色**：

| 认证名称 | 方向 | 层级 |
|---------|------|------|
| Claude Certified Associate – Foundations | AI 通识 | 入门 |
| Claude Certified Developer – Foundations | API 开发 | 入门 |
| Claude Certified Architect – Foundations | 系统架构 | 基础 |
| Claude Certified Architect – Professional | 系统架构 | 进阶 |

**价格与形式**：$99–$175 USD，通过 Pearson VUE 预约，线上监考。Anthropic Academy 的免费课程（有结业证书）是独立体系，任何人均可参加；Pearson VUE 的付费认证考试目前仅限 Claude Partner Network 合作机构的员工。

**对 JR Academy 学员的影响**：目前门槛是「所在组织是否加入了 Claude Partner Network」，个人直接报名通道暂未开放。如果你所在的公司正在使用 Anthropic 企业版，值得询问 HR 是否符合报考资格。开放后预计会成为 AI 工程师岗位简历上最有区辨度的证书之一。

### 2. Google Cloud 正式将 Professional 证书有效期从 3 年缩至 2 年，续期新通道 9 月 1 日截止

**一句话**：从 2026 年起，Google Cloud Professional 认证（PCA / PDE 等）有效期缩短为 **2 年**；同步推出的 Google Skills 续期通道允许 PCA / PDE / ACE / CDL 持证者完成指定技能徽章来延期 **12 个月**，一次性窗口截止 **2026 年 9 月 1 日**。

**有效期变化对照**：

| 认证层级 | 旧有效期 | 新有效期（2026 起） |
|---------|---------|-----------------|
| Professional（如 PCA、PDE） | 3 年 | **2 年** |
| Associate（如 ACE） | 3 年 | 3 年（暂未变化） |
| Foundational（如 Cloud Digital Leader） | 3 年 | 3 年（暂未变化） |

**续期新通道细节**：
- 适用对象：PCA / PDE / ACE / CDL 持证者，证书于 **2026 年 1 月 1 日后到期** 或将于 **2026 年 8 月 31 日前进入 inactive 状态**
- 操作：在 Google Skills（skills.google.com）完成指定技能徽章和课程
- 效果：认证有效期延长 12 个月（一次性机会）
- 截止日期：**2026 年 9 月 1 日**，距今 14 天

如果你持有上述认证且距到期不足 12 个月，这条免费续期通道是比重新备考省时省钱的选项。具体需完成哪些徽章，以 Google Skills 官网和你账户内的到期通知为准（登录 cloud.google.com/certification 查看）。

标准续期考试（非 Skills 通道）规格：25 道题 / 60 分钟，比初次认证（50–60 题 / 2 小时）短一半，难度同等。

> 来源：[Google Cloud Certification Renewal — support.google.com](https://support.google.com/cloud-certification/answer/9907853?hl=en)；[No more expensive exam fees? Google Cloud free renewal route 2026 — note.com](https://note.com/fallen_pear/n/n528ff6380673?hl=en)；[Google Cloud Changed Exam Delivery and Renewal Rules in 2026 — dailydebian.com](https://dailydebian.com/blogs/it-certification-news/google-cloud-changed-how-you-take-and-renew-certifications-in-2026)

### 4. Databricks Data Engineer Associate 5 月大改版：考试变得更"实战化"

**一句话**：Databricks 于 **2026 年 5 月 4 日** 对 Data Engineer Associate 认证考试进行了大幅调整，新版更聚焦实操、更贴近真实工作场景，旧版 dump 题几乎失效。

相比 GenAI Engineer Associate（昨天日报有介绍），Data Engineer Associate 是入门 Databricks 认证体系的基础路径，考察 Delta Lake、Spark、Databricks Workflows、Unity Catalog 的实际操作能力。5 月大改后有三个变化：

- **题型更实战**：减少了概念性选择题，增加了基于场景的判断题（给一段 code / pipeline 配置让你找问题）
- **考纲权重重组**：Delta Lake 和 Workflows 部分权重上调，纯 Spark API 理论部分权重下调
- **旧版资料参考价值降低**：改版前流传的 dump 题库命中率大幅下降，官方学习路径（Databricks Academy）是目前最可靠的备考资源

两张认证对比一眼看：

| | Data Engineer Associate | GenAI Engineer Associate |
|--|---|---|
| 定价 | 官网确认为准 | $200 USD |
| 考题数 | 官网确认为准 | 45 题 |
| 考试时长 | 官网确认为准 | 90 分钟 |
| 主要考察 | Delta Lake / Spark / Workflows | RAG / LLM Chain / MLflow |
| 改版时间 | **2026 年 5 月 4 日** | 2026 年 3 月 18 日 |

Data Engineer Associate 的定价和题目数量以 [databricks.com/learn/training/certification](https://www.databricks.com/learn/training/certification) 官方页面为准，以上表格中已知数字来自公开报道，请上官网核对最新考纲和费用。

**适合**：准备 AWS 认证、或想系统入门 AI 工程（不用花钱）的学员

AWS Skill Builder 提供 600 余门完全免费的自学课程，涵盖全系 AWS 服务。其中目前最值得关注的三条免费学习线：

**ML 方向（无代码入门）**：
- 课程：Machine Learning with Amazon SageMaker Canvas
- 内容：用 SageMaker Canvas（拖拽界面）做数据准备、模型训练、自动化预测，全程无需写代码

- 课程：Foundations of Prompt Engineering（Amazon Bedrock 平台）

以上课程均免费，无需信用卡，注册 AWS 账号即可访问。Skill Builder 还提供 10 个免费实操 Lab（AWS Builder Labs 免费学习计划），涵盖 EC2、S3、Lambda 基础操作，适合 Solutions Architect Associate (SAA-C03) 备考期的动手练习。

### 2. Harvard CS50：2026 年还是最强的真免费 IT 证书来源

**适合**：零基础转行 IT、或想补编程基础的学员（特别是 CS50P / CS50AI）
**链接**：[cs50.harvard.edu](https://cs50.harvard.edu/)

在「免费证书」遍地是 audit-only 的 2026 年，CS50 是少数真正不收钱还给正规证书的课程之一——通过 Harvard 官方平台 cs50.harvard.edu 直接颁发，不经过 edX 付费墙。

目前最适合 JR Academy 学员方向的三门：

| 课程 | 重点 | 时长参考 |
|------|------|---------|
| CS50P（Python） | Python 编程基础，从零到函数 / 文件处理 / 正则 / OOP | 10 周，每周 5–8 小时 |
| CS50AI（AI 导论） | 搜索、机器学习、神经网络、语言模型的工作原理 | 7 周 |
| CS50SQL | 数据库查询、索引、视图，直接练 PostgreSQL / SQLite | 5–6 周 |

**注意**：CS50 结业证书由 Harvard 颁发，但不是 accredited degree，也不是行业认证考试（不是 Pearson VUE 那种）——LinkedIn 上加进去证明你完成了哪门 Harvard 开放课程。含金量在「能力证明」而非「资格认证」。

证书完全免费，无截止日期，自己安排进度。

### 3. DeepLearning.AI × Hugging Face 短课合集：视频全部免费看

**适合**：有 Python 基础、想学特定 AI 技术点的中级学员
**链接**：[deeplearning.ai/courses](https://www.deeplearning.ai/courses/)

DeepLearning.AI 提供 124 门 bitesize 短课（每门约 1–3 小时），所有课程视频均可免费观看，其中多门与 Hugging Face 合作：
